# 8.3 游戏世界的维度

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：物理维度、时间维度、环境维度、感情维度、道德维度

## 原书内容整理

游戏是用很多属性来定义的。有的是数量方面的，可以用数值来表示，比如游戏世界的大小；有的是品质方面的，只能用文字来描述，比如游戏世界的气氛。一些属性是相互联系的，我们把这些相互联系的属性叫作游戏世界的维度（dimension）。为了完全定义游戏世界和环境，你需要考虑每个维度，并且回答相关的一些问题。
