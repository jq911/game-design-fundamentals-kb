# 8.2 游戏世界的目的

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：娱乐价值、幻想、探索、互动环境、销售吸引力

## 原书内容整理

游戏通过几种方式提供娱乐：游戏可玩性、新奇事物、社会互动（如果是多人游戏）等。在像国际象棋一样的游戏里，几乎所有的娱乐价值都来自游戏可玩性，很少有人把它当作一场中世纪的战争；在悬疑类的游戏（比如《寂静岭》系列游戏）里游戏世界实际上就是幻想。如果没有游戏世界，那么游戏本身根本就不会存在；如果游戏世界不一样，那么游戏肯定也会不一样。游戏世界的目的之一就是简单地在自己的范围内娱乐：给玩家提供一个探索的地方和互动的环境。玩家对于游戏的核心机制了解得越多，游戏世界就越不重要，这是个普遍规则。掌握国际象棋的玩家初学时会把棋子看成国王、王后和骑士。当玩家在游戏里的技术变得很高超时，比如说《军团要塞2》，他们就不会再关注身处何地，以及出现在那里的原因，他们只会考虑躲闪、移动、射击、埋伏、获得弹药等。然而，忽视游戏世界的抽象游戏，只存在于有经验的玩家中。对于第一次玩这个游戏的人来说，游戏世界对吸引和维持他的兴趣是至关重要的。游戏世界的另一个目的是把销售游戏放在第一位。真正吸引顾客选择购买的不是游戏的机制，而是它提供的幻想世界：他会是谁？他会在哪儿？如果他玩这个游戏，他会在那儿千什么？
