# 8.3.2 时间维度

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：物理维度、时间维度、环境维度、感情维度、道德维度

## 原书内容整理

游戏的时间维度定义了在游戏世界里对待时间的方式，以及它与现实世界里的时间不同的地方。在很多回合制游戏和动作游戏里，根本不包含时间流逝的概念：日、夜、季节、年。每件事都在一个不间断的循环上空闲或者运转，直到玩家以一定的方式和游戏互动。玩家偶尔也会被施加一定的压力，在限制的时间内完成一些事，但是这通常只适用于单个挑战，不是游戏时间概念的一部分。在有些游戏里，时间只是作为游戏世界的一部分而不是游戏可玩性的一部分。时间的消逝创造了气氛，给予游戏视觉上的多样性，但是并没有改变游戏的挑战和动作。这通常让人感到不真实。如果玩家在夜里可以做和白天一样的事情，好像没有人睡觉，那么就没必要来区分时间了。要想让时间真正支持幻想，必须用除了视觉以外的方法来影响游戏体验。《我的世界》就是一个时间真正有意义的很好的例子。《我的世界》中的大部分怪物在白天都不怎么活动。而到了晚上，周围也会和现实一样变得暗淡并且伸手不见五指。而在游戏的地下部分，外面是白天还是黑夜就显得意义不大了。

#### 1. 可变的时间

在把时间作为一个重要元素来实现的游戏里，游戏世界的时间通常比真实时间走得快。游戏的时间还会跳跃（就像书里和电影里一样），省略掉那些没有故事发生的时间。例如，大部分战争游戏根本不考虑夜间或者要求士兵休息。现实中，士兵的疲乏是战争中一个需要考虑的重要因素。但是，因为睡觉的土兵看起来不刺激，而且互动性肯定不强，因此大部分的游戏就省略了睡觉时间。允许士兵不间断地战斗，同时也是允许玩家不间断地玩游戏。《模拟人生》这款管理家庭的游戏，用另一种方法来处理这个问题。模拟的人物为了身体健康也需要休息和睡觉，所以这个游戏把白天和夜间分得很明确。然而，所有人物都睡了的时候，游戏会大幅度加速，让几小时在几秒钟内就过去了。只要有人醒来，时间就又慢了下来。《模拟人生》是一个不太常见的游戏，它主要是关于时间管理的。玩家始终处在压力之下，他的角色要赶快完成家务，挤出时间休息、放松，以及自我发展。这个游戏时间走的速度是现实生活中的48倍左右，所以游戏世界中白天的16小时，大概需要用现实生活的20分钟。然而，里面人物的移动速度不是原来的48倍，他们的行为看起来很正常，与现实世界里差不多。所以，出去取报纸这个动作大概要花费15分钟（根据游戏里的时间）。这加大了游戏的时间压力感。因为人物做什么事都很慢（游戏时间），他们常常没有时间浇花，结果花就会死掉。

#### 提示：“子弹时间”或“英雄时刻”，如在《马克思佩恩》和许多其他游戏中所见的，是可变

时间的另一个例子。当玩家参与战斗时，游戏会自动进入一个超级慢动作的模式。

#### 2. 反常的时间

《工人物语：帝国的崛起》是一款复杂的经济模拟游戏，在这里面一棵树从树苗长到正常尺寸，与铸铁车间熔化四五条铁块的时间差不多。这是采用反常时间的一个很好的例子：在游戏的不同部分好像有不同的时间速度。《工人物语》系列游戏的开发商Blue Byte，调整每个任务完成时间的长短，以保证游戏整体运行顺利。所以，《工人物语》以现实主义为代价成就了一个平衡性很好的游戏。然而这并不影响游戏的科幻性，因为这个游戏并没有在游戏世界里给玩家真正提供一个计时器，也就没有办法把游戏时间和现实时间做比较了。所以，这个游戏世界实际上没有明显的时间度量（如图8-7所示）

#### 3. 让玩家调整时间

在体育游戏和交通工具模拟游戏里，游戏时间走的速度通常和现实时间一样。一场美式足球游戏通常是1个小时，但是由于钟表老是暂停，足球游戏的实际时间要接近3个小时。所有严格计算机化的足球游戏都精确地模拟真实游戏。仿真性是很多运动游戏的关键要求，如果一个游戏没有精确地模拟真实的运动，联盟就不会支持它，它的竞争对手也一定会指出这个瑕疵。不过，大部分这样的游戏会允许玩家自己缩减游戏时间，把每小节15分钟改成5分钟或10分钟，因为大部分人不想把整整3个小时的时间用来玩模拟足球游戏。这对于测试也很有用。如果每次都要进行一个真实长度的比赛，将要花费很长的时间来测试这个产品。飞行模拟游戏通常也用现实的时间，但是经常会有路线很长的直航，没有有趣的事情发生，飞机只是简单地从一个地方飞往另一个地方。为了缩减这些，许多游戏在游戏世界里提供加速，2倍、4倍、8倍——事实上，让游戏里的每件事都比现实中快。当飞机靠近目的地时，玩家可以恢复到真实的时间维度下的正常速度。《上古卷轴5：天际》就可以让玩家自由更改游戏中的时间流逝速度。
