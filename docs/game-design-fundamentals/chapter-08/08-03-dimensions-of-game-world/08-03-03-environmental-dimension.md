# 8.3.3 环境维度

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：物理维度、时间维度、环境维度、感情维度、道德维度

## 原书内容整理

环境维度描述了游戏世界的外观和氛围。我们已经讲过，物理维度解释了游戏空间的属性；环境维度讲述的是关于那个空间里有什么。游戏世界的环境特点形成了创造艺术和音频的基础。我们会讲两个特殊的属性：游戏世界的文化背景和物理环境。

#### 1. 文化背景

我们说的游戏的文化背景，指的是人类学的概念：信仰、态度和游戏世界里人们的价值观，还有他们的政治和宗教习俗、社会组织等——简而言之，就是人们的生活方式。这些特征在游戏里的制作项目上都有体现：服装、家具、建筑、风景和游戏世界中其他人工制造的物体。文化不仅影响着什么该出现，什么不该出现（背景为古埃及的游戏中显然不能出现火器），而且会影响每个东西的外观——包括用户界面。《埃及艳后：尼罗河的女王》就是一个文化与用户界面协调得很好的例子，如图 8-8 所示。

物体的外观不仅受它在游戏世界里功能的影响，还受构造它们的人的审美观念的影响。例如，一个毛利人的徽章和欧洲中世纪的徽章看起来截然不同。



#### 2. 物理环境

游戏世界的物理方面——它所处的物理环境和内容——决定了游戏实际上是什么样子的。这是游戏设计的一部分，对于一个艺术家或从事与艺术很相近的工作是最有帮助的。在设计的初始阶段，你不需要把游戏世界里出现的每一个东西都画出来（尽管迟早会有人要画的）。目前重要的是创造概念草图：用铅笔或钢笔画出游戏里的关键视觉元素。这取决于你的游戏是什么类型的，可以包括建筑、交通工具、服装、武器、家具、饰品、艺术品、珠宝、宗教或魔力物品、商标或标志等。《冥界狂想曲》（如图8-9所示）

是一个很有特色的例子。构造人工制品尤其受游戏文化的影响。强大的虔诚的宗教信徒很可能会有代表自己精神的巨大的标志性建筑：石庙或大教堂。好战的游牧民族会让动物或者交通工具携带他们的工具和武器，适于途中使用（注意这些骑着骆驼的人将来可能成为游牧民族）。

#### 3. 细节

每个设计者都必须决定游戏世界需要的详细程度——也就是说，这个世界的结构要多精细，它的特征要模仿得多精确。在一定程度上，你的答案取决于你追求现实主义的程度，但是技术和时间上的约束会限制你的做法。没有哪个足球游戏会把体育场的电扇都模拟出来，也很少有飞行模拟游戏会模拟飞机的每个物理特点。细节有助于支持科幻性，但总是有代价的——即开发时间或玩家机器的磁盘空间。在冒险类游戏里，原则上来说，应尽可能地去模仿现实世界中的每个细节，但是事实上，这在技术层面上是不切实际的。而且玩家们很理解不去过分纠结细节的原因，那就是：计算机运行容易死机。所以玩家知道，某个物体被选来模仿，在某种程度上肯定是因为它重要；如果不模仿它，它就是不重要的。你所选择的视角模式，以及玩家在游戏世界中的移动方式，都可能会影响你对细节级别的决定。例如，在诸如温布尔登网球场这类小型体育场中，通过运动员视角可能会看到观众人群中的某些人物，因此对观众进行详细建模便有其道理。然而，在赛车游戏中，观众区只会闪过一片模糊的景象，因此在他们的外表上建模便没有什么意义了。这里有一个很好的规则用来决定你的游戏该包含的详细程度：加入尽可能多的细节，让游戏更吸引人，但是不要太多以至于损害了游戏可玩性。如果玩家必须费很大劲去检查你提供的每个细节，那么游戏的细节可能就太多了。（这就是战争游戏为什么往往只有几百个而不是成千上万个单位的原因。战争游戏的玩家不可能给这么多智能下属分配任务，所以要把数量保持在他能够控制的范围内。）一个细节非常详细但是玩起来不顺畅的游戏根本卖不出多少份。

#### 4. 定义一种风格

在描述你的游戏世界看起来是什么样时，你就给游戏定义了一个视觉风格，这也会影响许多其他的方面：角色设计、用户界面、游戏指南，甚至还有包装盒和广告设计。在这里你其实有两个任务：定义游戏世界里面物品的风格（即内在风格），还有定义描述游戏世界中艺术品的风格。两者是不一样的。例如，你可以描绘一个世界，里面的建筑风格是受佛教寺庙的启发，但是却把它画得像一个灰色电影。或者你可以有一个半木建筑结构的中世纪小镇，但是把它描述成有一点模糊的印象派风格。你必须选择内容和展示内容的方式。这两个决定在很大程度上都会影响玩家的游戏体验，共同创造一个明确的氛围。一般来说，描述的风格往往会把它的气氛附加在被描述的物体上。例如，一个希腊寺庙建筑可能看起来很高雅，但是如果它的绘画风格像米老鼠卡通里面的，那人们就会预测有古怪或者荒诞的事儿要在这儿发生。绘画风格把自己的氛围加到了寺庙上，不管是多壮丽的一个庙。例如，《火影忍者疾风传：终极忍者风暴》（如图8-11所示）

里面所有的地点都呈现出统一的平面阴影着色方式，这会让人想起赋予这个游戏灵感的那本漫画书。

> 提示：艺术风格的选择可以对游戏美术工作所需的时长产生显著影响，这是要与游戏的美工负责人密切商量的另一个原因。如果游戏不太依赖于特定的风格，那你可以通过使用不同的风格来节省时间和金钱。

#### 5. 过度使用背景

游戏经常会借鉴其他游戏的背景，或者从电影、书本、电视上借鉴常见的背景。大量的游戏是设在科幻或幻想世界里的，尤其是类似于中世纪的剑术或巫术的想象，它们受到了J. R. R. Tolkien和《龙与地下城》的启发。这种游戏在年轻人之间很流行，年轻人曾占有电子游戏的主要市场——实际上，几乎是唯一的市场。但是现在玩游戏的人多了，他们期待尝试新的游戏。你应该超越游戏中那些古老的产品。《州际76》受20世纪70年代的电视剧所启发。游戏中包含那个年代的车、服装、音乐、语言，它们都是很有特色的，并且能唤起对特定文化的回忆。《州际76》有很高的游戏可玩性，真正使它区别于竞争者的是：它看起来、听起来都跟市场上的其他东西完全不一样。如果你正准备设计科幻或幻想游戏，尽量把你的环境做得有特色和与众不同一些。现在，美国和俄罗斯制造的航天器看起来非常实用，随着航天器越来越普及，特别是我们开始见到私人宇宙飞船时，我们也会期待它们展示风格上的不同。这是一个有着无限创新自由的领域。对于幻想游戏也是一样。丢开那些既单调又过时的精灵、矮人、巫师和龙（如图8-12所示）

  <img src="../../../../assets/book-images/game-design-fundamentals/chapter-08/figure-8-12-medieval-fantasy-example.png" alt="图8-12 另一款仿中世纪的游戏：《幻魔霸主》" loading="lazy">

。去别的文化里寻找英雄和恶棍。现在游戏里出现的非西方文化只有日本文化（封建的、现在的、未来的），因为日本人开发了很多游戏，所以他们的风格也被西方人慢慢接纳了。但是世界上还有很多其他的灵感来源，很多是尚未开发的。在公元1200年左右，欧洲的统治者仍躲在狭窄的、透风的城堡里，而伊斯兰文化却正值顶峰，建造了充满东方财富的宏伟的宫殿，镶嵌有宝石的壮丽的清真寺。但是这个辉煌出色的文化几乎还从没在计算机游戏里出现过。因为西方游戏设计者不想花费心思去学它，或者根本不知道它的存在。把你的幻想设置在彼得大帝在位时期俄国的瓦尔哈拉殿堂里，或者设置在极地的寒冰苔原上，或者设置在吴哥窟的寺庙上，或者设置在复活节岛的石像旁，或者就设置在秘鲁马丘比丘的古城里。如果设计的游戏中加入了你不熟悉的文化，一定要找相关的专家进行咨询，以免描述失当引起不必要的麻烦。游戏巨头Activision（动视）公司推出的《荒野枪神》是一款描述美国西部牛仔时期的游戏，其中对美洲原住民形象的刻画就引起了很大的非议。



艺术和建筑、历史和人类学、文学和宗教、服装时尚，还有产品设计都是文化素材很好的来源。尤其是美术和建筑学的进展提供了大量的财富：流行艺术、装饰艺术、帕拉迪奥建筑风格、野兽派建筑风格。如果你没有听说过其中的某一个，现在就去调查。上网搜索或者去书店和图书馆的艺术区、建筑区、设计区看看，寻找有趣的物体、建筑、服饰的照片。带上数码相机，把吸引你眼球的东西照下来，把这些图片贴在你的工作室里，用来启发你自己和同事们。从每个地方收集有用的点点滴滴，看看国家地理的旧杂志；如果有机会，去参观艺术、设计、自然历史的博物馆；如果你支付得起，最棒的资源是旅游。一个好的游戏设计者总是在寻找新鲜的观念，哪怕表面上在度假的时候也是如此。向我们最亲近的视觉邻居（电影）学习，是很有诱惑力的。因为电影制片商已经为我们完成了视觉设计工作。《银翼杀手》介绍了衰退的城市的未来，《异形》系列展示了令人恶心的外星怪物而不是绿皮肤的小外星人。但是这样的问题是，它们已经被抄袭过很多次了。如果你不想努力开发你的世界，那么可以把它们当作一个质量低劣的背景，不过玩家会很快就认出这个世界，知道这个游戏是关于什么的。要想与众不同，就需要考虑一下其他的题材。例如马克斯三兄弟的黑色电影，约翰·韦恩的西部片，二战时期的战争电影，以及各个时期的古装剧——从愚昧的《史前一万年》到优雅的《傲慢与偏见》，都是很好的素材。电视经历了属于自己的发展阶段，由于它跟电影相比更受时尚所驱动，它的模仿技术已经成熟。20世纪五六十年代的喜剧和七八十年代的夜间肥皂剧，都有着自己典型的风格，现在看起来仍然很可笑，对于大部分美国成年人来说，它们仍是非常熟悉的。这样也不是没有风险的，如果你毫不保留地参照了美国的通俗文化，那么非美国人和小孩就会看不懂。不过如果你的游戏可玩性足够好，那么这也就不成问题了。漫画书和儿童书籍的风格与众不同，也可以作为灵感的来源，尤其是当你打算设计一款2D类游戏的时候。已经有大量的游戏从少儿读物中复制出它们的艺术风格，其中做得最好的就是《莫里斯·莱斯莫先生的神奇飞书》。
