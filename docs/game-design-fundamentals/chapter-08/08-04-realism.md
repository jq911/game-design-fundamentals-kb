# 8.4 现实主义

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：现实主义、抽象、仿真、娱乐性、设计目标

## 原书内容整理

第2章里在讲述核心机制的背景时，我们讨论了现实主义的理念。所有游戏（不管多现实）都是对现实世界的抽象和简化。哪怕是耗资数百万美元，为了培训商业飞行员的飞行模拟器，也不能把驾驶座弄得底朝上。在客机里这种事儿很少发生（希望如此），所以不值得另外花钱去模拟。游戏中任何方面的现实主义程度都在以高度写实和高度抽象为两个端点的连续区间上。玩家和游戏评论者经常会把现实主义作为评价整个游戏的质量标准，但事实上，游戏中各个部分的现实主义程度并不一样。许多游戏有很真实的图像，同时在物理学上却很不现实。很多第一人称射击游戏精确地模仿了各种武器的外部特征——速度、子弹夹的规格、精确度等——但是允许玩家一次携带10个，而且不降低速度。所以，现实主义不是游戏世界一个单独的维度，而是一个多变量的特征，适用于游戏里面的各个部分。

> 提示：如果你喜欢数学，可以把现实主义当成一个适用于游戏中各方面的向量，它的取值范围是0（完全抽象）到1（完全现实）。然而，没有哪个值能等于1，因为游戏里的任何东西都不是完全真实的——如果等于1，那么它就是生活而不是游戏了。

现实/抽象二分法主要用在你开始考虑要制作何种类型的游戏时。一方面，如果你设计一个卡通动作游戏，比如《瑞奇和叮当》，你知道它的大部分都是抽象的。在设计游戏元素时，你需要问自己要包含多少现实。你的化身从很高的地方摔下来会不会受伤？他能携带的重量有没有限制？牛顿物理学在它身上适不适用，还是它可以在半空中改变方向？另一方面，如果你设计一个人们希望是现实的游戏——例如，交通工具或者运动模拟游戏——你就需要从另一个方向进行考虑了。现实世界的哪些方面将会被去掉？很多现代的战斗机几乎有几百个操作装置，这就是为什么很少人能成为战斗机飞行员。为了让飞行模拟游戏被公众所接受，你必须简化里面的这些装置。同样，战斗机的引擎非常强大，以至于有些军事演习能把飞行员弄得失去知觉，甚至把飞机撕裂。你是准备精确地模拟这些装置，还是不要求玩家考虑这些，把游戏变得抽象一点？正如我们所说的，你做的每个设计决定都要服务于游戏的娱乐性。另外，每个设计决定都必须服务于游戏整体的现实主义目标。有些题材要求的现实程度要比别的高一点。在哪个领域和创建多少真实程度是由你来决定的。在设计过程中，你必须不断考量你的决定，确保它们符合你的目标。
