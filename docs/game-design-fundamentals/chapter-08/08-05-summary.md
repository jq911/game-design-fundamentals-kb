# 8.5 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：总结、游戏世界、维度、现实主义、幻想世界

## 原书内容整理

现在，你应该知道游戏发生的时间地点。你已经回答了大量类似于这样的问题：你的游戏世界看起来是什么样子的，听起来像什么，谁生活在那里，他们的行为方式是什么样子的。如果你已经彻底完成了这些，你的游戏世界就会令玩家沉浸其中，因为这是一个他们信任的、喜欢参与的可靠的幻想世界。下一步就是要搞清楚那里将会发生什么。
