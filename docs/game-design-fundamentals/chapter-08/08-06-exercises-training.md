# 8.6 设计练习——训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：训练题、情感基调、道德系统、游戏世界分析

## 原书内容整理

1.假设你可以在游戏中使用任何想用的东西，而不需要考虑版权问题。在以下的游戏类别

中选择一个，然后选择一个画家、摄影师或电影制片人、作曲家或音乐家，用他们的作品为你的游戏奠定一个合适的情感基调。做一个简短的展示（PPT或类似的）说明你打算如何将这些元素结合在一起。供选择的游戏类别有：动作类（恐怖生存类）、实时策略类（现代战争）、儿童非暴力冒险类。

2.写一篇论文讨论你玩过的游戏中两个形成鲜明对比的道德系统（或是由指导老师分配的两个

游戏）。观察两个游戏对什么样的动作进行奖励，对什么样的动作进行惩罚。并分析这两个游戏世界中道德行为和现实世界道德行为之间的关系。
