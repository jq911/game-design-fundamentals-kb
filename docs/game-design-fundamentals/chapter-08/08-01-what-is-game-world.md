# 8.1 什么是游戏世界

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 8 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏世界、魔法圈、想象空间、环境、抽象游戏

## 原书内容整理

游戏世界是一个模拟的世界、一个想象的地方、游戏事件发生的地方。当玩家进入魔法圈，假装处在另一个地方，那里就是游戏世界。不是所有的游戏都有游戏世界。足球游戏在一个真实而不是想象的地点发生。踢足球仍然需要假想，因为玩家给那些本来不是很重要的动作加上了人为的重要性，但是这样的假想并没有创造一个游戏世界。许多抽象游戏，像井字三连棋有一个棋盘，但没有游戏世界——在这个游戏里没有想象的成分。《陆战棋》有一个稍微复杂的世界，棋盘装饰得像一幅风景，每个棋子都有小图片说明，鼓励我们把它们想象成陆军里的上校、中尉和侦察兵。《陆战棋》可以完全抽象地玩，只用数字和简单的网格，但是这个环境让它更加有趣。除了一部分像《音乐涂鸦》这样的抽象类游戏外，电子游戏通常都可以通过艺术、动画、音乐和声效等手段来构建出大量丰富的游戏世界。

①一种棋类游戏，起源于欧洲近代的战争。一译者注

#### 设计点拨：你不是自己的玩家

在定义游戏世界的时候，你是否会迫不及待地开始描绘它的画面呢？尤其是当你是一位艺术爱好者的时候。这种绘画创作对于设计的早期阶段来说是很好：你需要艺术上的作品来表现游戏。但同时也要注意，不要想当然地认为把画面画得好看就够了。游戏世界必须和游戏的核心机制与游戏可玩性相映成趣。而为了做到这一点，在定义游戏世界时必须十分仔细谨慎。否则，你可能会忘记处理某些重要的问题，待到木已成舟便悔之晚矣。电子游戏里的游戏世界通常是通过图片和声音（美术、动画、音乐、音效）来展示的。然而，不是所有的游戏世界都有可见或可视的成分。在一个文本冒险游戏里，玩家读屏幕上的文学来为想象中的世界创造图片和声音。设计这样的游戏是利用你的文学能力使用文字来描述它。游戏世界不只是描述它的图片和声音的总和。一个游戏世界可以包含一种文化、一种美学、一套道德观，还有一些其他方面的内容，本章会——解释。不管游戏世界是如何高度抽象的，即它和日常生活几乎没有什么联系，还是高度写实的，力求和现实世界尽可能相似，游戏世界都和现实是有联系的。
