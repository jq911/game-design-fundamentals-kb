# 第 10 章 角色开发

## 本章定位

本章讨论如何设计令人信服、可识别且能承载游戏体验的角色。重点从化身与玩家关系、视觉外表、角色深度、属性与成长，以及音效、音乐和语言等方面，说明角色如何服务于可玩性、叙事和商业识别。

## 复习线索

- 好角色应当吸引人、可信，并能让玩家理解或认同其在游戏世界中的位置。
- 化身设计需要处理玩家自定义、指定化身、控制机制和玩家投射之间的关系。
- 视觉外表包括身体类型、衣着、武器、标志性物品、名字、调色板与同伴等识别要素。
- 故事驱动角色设计关注角色的作用、态度、价值、属性、维度、成长与人物原型。
- 音频设计通过音效、音乐主题、声音、词汇、语法、口音和说话风格进一步定义角色。
