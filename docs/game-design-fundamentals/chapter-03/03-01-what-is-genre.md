# 3.1 什么是游戏类别

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏类别、挑战、内容、子类型、混合类别

## 原书内容整理

在描述电影和书籍的时候，“类别”代表的是其中的内容。历史小说、言情小说、间谍小说等都是不同类型的通俗小说。而在电子游戏行业中，类别表示游戏中提供的挑战。在游戏里，类别是独立于游戏内容之外存在的。像射击类游戏，可以发生在古代的西部、魔幻的世界，或是外太空等，但统统属于射击游戏。“类别”在游戏中指特定种类的挑战，与游戏设置或游戏世界中的其他内容无关。最早的电子游戏通常是在有限的硬件设备上运行，因此能提供的可玩性不多，所以还没有类别之分。只有像《太空射击》这样的街机游戏才能看得出是纯粹的动作游戏，而《星际迷航》则是典型的策略游戏。现在很多新型的游戏往往混合了多种游戏类别，有时他们会在单一的可玩性模式上进行这种设计。例如《杀出重围》就是这样一款不俗的游戏，它在RPG类型的射击游戏当中，加入了资源管理和人物成长挑战。其他的会在不同的游戏模式中加入多种形式的挑战，《奇异世界：回到无限的太空》就是这样一款游戏，游戏中有包括探索和资源管理方面挑战的高级别的回合制模式，也有低级实时作战模式。现在很难把一个游戏明确地分为某一类，尤其是那些基于网页的小型游戏和手机游戏。随着这两个新型游戏平台的出现，这方面的游戏开发也得到了爆炸式的增长。像《粘粘世界》（如图3-1所示），就不能简单地划分到传统类别中的某一类中。

#### 子类型

有时游戏分类是非常有用的，它可以将游戏划分为数个小型的集群或次类型，这样就能更好地让人理解游戏有哪些可玩性。像第一人称的射击类游戏，就有许多种子类型，如：竞技场类型，一种快速的多人竞赛模式（《军团要塞2》就是个典型的例子）；战术射击类型，利用潜行和有限的弹药来争取最大的战果；开放性的游戏类型，如《战地》系列；最后还有定轨射击类游戏，玩家的活动是受限制的，只能在一个画面内自动移动。同样，汽车赛车游戏可以分组到提供作战模式和没有提供作战模式的类型中。这些分类会根据开发者、游戏舆论以及玩家本身的想法而不断变化。而作为一个掌握着自己游戏类型决策权的游戏设计师，你应该学习现有的游戏，尤其是和你想要设计的相类似的游戏，以及人们交口称赞过的游戏，这样便能更好地掌握游戏在市场上的位置。
