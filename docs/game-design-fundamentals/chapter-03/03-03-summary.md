# 3.3 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：本章总结、类型框架、玩家解释、风险降低

## 原书内容整理

你现在知道了游戏行业的主要类型和次要类型，以及它们中的典型游戏。当然本书无法列举所有游戏名称，只写了最著名和最畅销的。类型注定不会限制你的想象力，但它们提供了框架设计的经验，框架设计完成后，就无须再一切从零开始建立你的游戏——这会降低设计一个新游戏时的风险。设计一种著名类型的游戏也可以帮助你更好地向资助机构、零售商和玩家解释你的游戏。在第4章中会讨论玩家和他们对游戏里丰富细节的态度。68
