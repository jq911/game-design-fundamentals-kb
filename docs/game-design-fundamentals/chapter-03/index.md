# 第 3 章 游戏类别

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，当前已完成初步 OCR 拆分，后续仍建议逐段人工校对并继续完善图示截图。

## 本章定位

本章介绍电子游戏类别的定义、类别与挑战的关系，以及经典游戏类别（射击、动作、策略、角色扮演、体育、模拟、冒险、解谜等）的基本特征。
