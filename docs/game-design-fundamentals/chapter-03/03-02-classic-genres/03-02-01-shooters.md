# 3.2.1 射击游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

在射击游戏中，玩家使用某些种类的武器，在远处动作。因此射击游戏要求的关键技能是瞄准，特别是当游戏提供的弹药有限时。在一个射击游戏中，玩家的注意力一定要同时放在两个地方：化身（即角色）所在区域和他正在射击的目标。射击游戏可以分为两个大类：2D 射击游戏和3D 射击游戏，3D 射击游戏到目前为止最著名的就是第一人称射击游戏。

#### 1. 2D 射击游戏

2D 射击游戏中的动作发生在一个从上下视角或者侧向观察视角观看的环境中，有时候也会以固定的第一人称视角出现（如图3-2所示），这种情况下的敌人会从屏幕中由内向外冒出来。化身，通常是一个人物或者交通工具，处于敌人近乎持续的攻击之中，这些敌人都在很近的距离内向它射击或者接近它来攻击。大部分情况下，玩家的目标就是简单地尽可能快地向所有移向它或者威胁它的东西射击，因此这种游戏也称为“Shoot-'em-ups”。玩家通常装备有一个或者多个武器，而且某些武器比其他武器更适合攻击某些特殊的敌人。除了允许攻击的目标，武器很少会对其他东西造成伤害。

#### 2. 3D 射击游戏

像《光晕》和《半条命》这样的3D 射击游戏已经非常成功了，以至于对某些游戏玩家来说它们就是这类游戏的代表。3D 射击游戏比2D 射击游戏更加真实，里面的游戏世界对于玩家来说更为熟悉，或者至少更加容易识别（如图3-3所示）。在第一人称射击游戏中，游戏的物理世界更像真实世界。重力也正常地起作用（在最大程度上），声音随着距离变得越来越小，物体具有影子，而且冲撞也按照相当高的精确度进行建模。3D 射击游戏可以进一步被划分为使用第一人称视角游戏（第一人称射击游戏或者FPS，first-person shooter）、使用第三人称视角游戏或者一些两种视角都提供的游戏。第一人称视角有时保留步枪射程或视线范围内的视图，而当化身移动时则可能看不清楚。
