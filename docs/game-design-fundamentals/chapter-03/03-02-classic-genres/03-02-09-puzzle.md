# 3.2.9 解谜游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

在解谜游戏里，解谜是首要的活动，虽然谜题可能会在故事情节里出现或者引出更大的目标。这并不意味着你可以提供一个谜题的随机组合就把它称作游戏，益智类游戏通常提供与某个主题相关的挑战和变体。提供的谜题类型包括模式识别、逻辑推理、理解一个过程。总的来说，谜题就是给玩家一些线索，拆开或解开就能满足胜利条件。《愤怒的小鸟》和《割绳子》（如图3-12所示）是两个例外，它们只需试错就可以通过。

而寻找隐藏物品的游戏可以算作解谜游戏，尽管它的挑战只是在一个复杂的情景中凭观察找到所需物品。随着基于网页和智能手机的游戏开始盛行，解谜类游戏在2000年左右迎来了市场的黄金时期，发行量上升。它们是休闲游戏的主要类型，而且也不用去过于追求娱乐性和成功。举个例子，《宝石迷阵》需要玩家匹配三个相同的宝石然后便可将其从网格中删除，但是随着旧宝石的消失，新珠宝会立刻出现补齐，因此就会出现多种可能性，这就需要玩家开动一点脑筋。解谜游戏提供逻辑挑战与概念性的挑战，虽然它们偶尔包括时间压力或行动的元素。它们也经常提供多种解决方案。
