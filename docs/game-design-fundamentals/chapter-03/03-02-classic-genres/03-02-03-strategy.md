# 3.2.3 策略游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

策略游戏是讲究策略的游戏（显而易见的），因此会包括战略、后勤和逻辑等多方面的挑战。有时也会加入经济和探索挑战来延迟游戏时间，丰富游戏类型（如图3-6所示）。

  <img src="../../../../assets/book-images/game-design-fundamentals/chapter-03/figure-3-6-napoleon-total-war-strategy.png" alt="图3-6 《拿破仑：全面战争》，一款实时的策略游戏">
  <figcaption>图3-6　《拿破仑：全面战争》，一款实时的策略游戏</figcaption>
</figure>

游戏进行一段时间之后，还会出现实体对抗，但这对于那些有战略思维的玩家来说，并不是很感冒。策略游戏挑战玩家通过计划来获得胜利，特别是通过计划和一个或者多个对手对抗的一系列动作。这个定义把策略游戏和益智游戏区分开了，后者要求没有冲突的计划。它也和竞技型建设和管理模拟游戏区分开了，模拟游戏要求计划，但是没有直接和对手对抗的动作。策略游戏经常把减少敌人的力量作为自己的主要目标，所以大部分策略游戏都或多或少有一点抽象的战争游戏。例如，西洋跳棋（国际跳棋）就是一个抽象的战争游戏；《Risk》不那么抽象；《轴心与同盟》，一个关于二战的棋盘游戏，就具有相当的表象性了。策略游戏被划分为两个主要的子类：经典的回合制游戏和实时策略游戏。纯策略游戏（那些只包含冲突挑战的游戏）一般都是回合制的，而不是实时运行的。
