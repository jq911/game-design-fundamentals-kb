# 3.2.8 冒险游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

冒险游戏跟市场上其他游戏有很大的不同。冒险游戏不是竞争或者模拟。冒险游戏不提供一个程序来让你经营，也不是让你用战略战术打败对手。相反，冒险游戏是关于玩家控制的一个人物的互动故事（如图3-11所示）。这个人物是玩家的化身，但是他不只是玩家的一个代表。他是一个虚构的独立人物、一个主角、故事的主角。

<figure class="book-figure">
  <img src="../../../../assets/book-images/game-design-fundamentals/chapter-03/figure-3-11-heavy-rain-adventure.png" alt="图3-11 冒险游戏《暴雨》">
  <figcaption>图3-11　冒险游戏《暴雨》</figcaption>
</figure>

虽然角色扮演游戏和冒险游戏都拥有这种品质，但RPG游戏通常提供大量数字化的人物成长系统（如等级、武器、技能等），而冒险游戏却不是这样，它们的角色成长是戏剧化的，而不是数据化的。作为一款冒险游戏的设计师，你的工作不仅是带来一个故事那么简单，而是要创造另一个世界——简言之，就是一个发生在另一个世界的故事。你在其余类型游戏设计中用不上的才能，在这种游戏中都将派上用场：如人物设计、情节、对话和解谜等。冒险游戏主要提供简单的探索和解谜挑战，有时也会包含观念挑战。纯粹的冒险游戏也会有实体对抗，但是这种情况非常少见。
