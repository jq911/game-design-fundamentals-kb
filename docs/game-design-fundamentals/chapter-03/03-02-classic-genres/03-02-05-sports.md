# 3.2.5 体育游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

体育游戏对游戏设计者来说是一个特殊的挑战。这么多人参与或观看体育运动，所以他们对游戏可玩性和游戏视觉设计有很高的期望，设计者必须想办法满足这些人的期望。然而，体育游戏仍然是所有电子游戏里最受欢迎的类别之一，一个设计良好的游戏可以创造一个非常令人愉快的——而且有利可图的——产品线。不像其他类型的游戏，玩家对游戏中的世界知之甚少，体育游戏中的世界正是玩家熟悉的现实世界的模仿：人人皆知的体育赛事。现实中没有人真正带领过一支由精灵组成的军队参加战斗，也只有少数人知道怎样驾驶一架F-16战机，但大部分人都知道什么是足球，也知道该怎么玩。体育游戏的设计通常提倡和真实世界直接进行对比（如图3-8所示）。

当然，并不是所有体育游戏都是极端现实主义的。有的，比如说Electronic Arts公司的怀旧 Sega Genesis游戏《木乃伊美式足球》就是一个虚拟的游戏，尽管它也是以真实体育运动为基础的。其他游戏，比如Midway的街机游戏《美式橄榄球闪电战》，简化了一种体育项目，而且为了引人注意故意把它做得更极端。滑雪类的游戏通常都属于这种。很多体育游戏致力于模拟真正的比赛，但是有很多也包括大量的管理职能——管理一个团队或一个运动员生涯的挑战。也有一些体育游戏只有管理职能，不让玩家控制比赛中的单个运动员。有时称为经理游戏，它们在欧洲非常受欢迎。
