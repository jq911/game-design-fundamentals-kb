# 3.2.7 建设和模拟类游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

建设和模拟游戏又称作建设与管理模拟游戏（CMS），常常给玩家提供构造某些东西的机会，例如蚁穴或者城市，同时在经济条件的限制下进行操作（如图3-10所示）。建设和管理模拟游戏是关于过程的游戏。玩家的目标不是打败敌人，而是在正在进行的环境内建造一些东西。玩家对于程序了解得越多，控制得就越好，在建设方面就会越成功。CMS一般为玩家提供自由建设模式，玩家可以随意建造东西和预设情节模式。CMS常常包括两套工具：建设工具和管理工具。建设一般是比较容易的，而管理的确很棘手。

这些游戏主要提供经济和概念方面上的挑战。它们中很少涉及冲突或探索，几乎从来不包括实体的挑战。
