# 3.2.6 交通工具模拟游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

交通工具模拟创造了一种驾驶交通工具（真实的或者虚构出来的）的体验。如果是对真实交通工具的模拟，那么其主要目标之一就是逼真性，即与现实是否有紧密的联系（如图3-9所示）。你可以假设玩家对这些机器了解得比较多，他们想要的体验是：至少视觉上跟真正控制一个机器差不多。

<figure class="book-figure">
  <img src="../../../../assets/book-images/game-design-fundamentals/chapter-03/figure-3-9-speeding-flying-car-4-cockpit.png" alt="图3-9 《竞速飞驰4》的座舱视界">
  <figcaption>图3-9　《竞速飞驰 4》的座舱视界</figcaption>
</figure>

如果你在设计一个虚拟的交通工具，你可以随意创造任何驾驶体验，不用受引力、重力、燃油储备量等方面的限制。只需要创造运动的感觉，你可以给这种运动加上任何限制。交通工具模拟游戏中最主要的子类别就是飞行模拟和驾驶模拟，尽管也存在太空和水上交通工具模拟，如开船和开火车。飞行模拟分为两大类：民用和军事。赛车模拟也往往分两类：有组织的竞赛和虚构的竞赛。有组织的竞赛模拟试图再现在已经存在的赛事，如印地车赛。而有些类别在驾驶过程中加入了战斗模式。
