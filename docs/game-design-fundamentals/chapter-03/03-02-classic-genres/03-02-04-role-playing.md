# 3.2.4 角色扮演游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

角色扮演游戏（RPG）允许玩家以更广的方式与游戏世界进行交互，比大多数其他游戏类型能发挥更丰富的作用。角色扮演游戏允许玩家体验现实中不可能实现的某些东西：从一个普通人到一个具有惊人能量的超级英雄的成长的感觉。很多游戏都立即提供给玩家这种能力，但是在角色扮演游戏中，玩家通过经验和选择希望培养哪一项特殊的技能来获得它们。计算机角色扮演游戏（CRPG）的重要组成部分是推进游戏故事的进展（如图3-7所示）和游戏人物的成长。故事的推进一般需要通过一些战斗来完成，以及一些为支撑故事而设计好的游戏规则。这些规则会定义游戏人物何时成长。因此一个成功的CRPG取决于一个扣人心弦的故事和有意义的人物成长经历。

大多数的角色扮演游戏涉及战术、后勤和探索的挑战。它们还包括经济的挑战，如收集战利品和交易更好的武器。有时包括拼图和概念性的挑战。老版的CRPG从来没有包括采取行动的内容；它们使玩家通过回合制的选择实施打击（益智游戏仍然使用这种方式）。现代的CRPG已开始将实体挑战作为战斗模型中的一部分，但这种类型的游戏很少，而且和格斗游戏一样难以操作。CRPG和其他很多类别的游戏拥有共同的元素。这是它们实现游戏的方式，也是它们发生的组合方式，正是这些元素把CRPG和其他游戏区分开来。因为CRPG包含了如此多的挑战类型，所以人们制作混合类别就不奇怪了。
