# 3.2.2 动作和街机游戏

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

动作游戏通常包含身体对抗。在这种游戏中，也经常也含有解谜、竞争，以及各种不同的战术冲突等挑战。这类游戏通常在少数几个角色之间进行。动作游戏通常包含简单的经济挑战，如收集对象之类。它们很少包括战略或概念上的挑战。街机游戏是为了从玩家投币这种机制中获得更多盈利而设计的游戏，一般来说玩家很难取胜，游戏会越玩越难，直到玩家疲于应对而输掉——这时玩家可以投入游戏币，再玩一次。动作游戏可以进一步细分为各种子类型。其中最著名的两种是平台游戏和格斗游戏。

#### 1. 平台游戏

平台游戏是卡通化的游戏，在这种游戏中，化身在一个垂直方向很夸张的环境中移动，在不同高度的平台上跳上跳下，避免障碍同时和敌人战斗（如图3-4所示）。化身拥有非自然的跳跃能力，而且从很高的地方跳下来时不会受到伤害（除非他跳到某些危险的东西上或者跳进一个无底的沟中，这些都是平台游戏常见的特征）。玩家的大部分动作都由跳跃组成，通过各种各样的翻滚移动或者环境中有弹性的物体增多弹跳的程度。平台游戏使用非现实的物理规则，化身通常可以在半空中改变方向。

#### 2. 格斗游戏

格斗游戏与其他动作游戏没有太多相同之处，因为它们没有涉及探索、射击或者解谜。它们几乎自成一种类别，但是我们把它们包含在这里是因为它们确实在很大程度上要求玩家的物理技能：反应时间和时机。它们通常模拟近身的打斗，含糊地使用亚洲武术技巧做出非常夸张的动作（如图3-5所示）。一个拳击游戏更应该属于体育类游戏，因为它们尽量真实地模拟了拳击的技术。格斗游戏也可以进一步细分为玩家之间单对单的比赛（竞技场模式），或者一两个玩家合作去对付一大群的敌人的比赛（混战模式），格斗游戏也使用局部效果的武器（例如剑和盾牌），以及有限数量的其他武器。
