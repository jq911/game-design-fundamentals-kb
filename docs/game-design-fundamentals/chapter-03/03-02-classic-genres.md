# 3.2 经典的游戏类别

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：射击、动作、策略、RPG、体育、模拟、冒险、解谜

## 原书内容整理

本节主要介绍一些经典的游戏类别，同时列举出各类型中的典型游戏，并截取它们的游戏画面作为插图。如果你想对某一个特定的游戏类型了解更多，可参阅Peachpit出版社出版的一系列电子图书，每本书都以《某游戏设计基础》方式命名，每一本书都对特定的游戏类型进行了详细的介绍。在第1章的表1-1中，列出了各种类型挑战，它们为玩家提供了娱乐，请读者好好记住这些类型，因为下面要介绍的几种类别在名字上和它们非常相似。
