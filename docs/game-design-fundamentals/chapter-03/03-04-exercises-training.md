# 3.4 设计练习——训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：训练题、游戏分类、平台、玩家偏好

## 原书内容整理

#### 1. 游戏分类变化较大。尝试观察以下游戏平台上的游戏类别：MobyGames、雅虎游戏

（Yahoo! Games），以及安卓或苹果应用商店中的手机游戏。其中哪些游戏类别呈现或缺乏不一样的定位？什么原因导致其差异？

#### 2. 简述你喜欢的游戏类别、不太关注的游戏类别以及特别不喜欢的游戏类别，并说明怎么

区分它们。请你从一个玩家的角度谈谈以上问题。与你所认识的并且游戏类别喜好不同的人谈谈以上问题，考虑你们喜好不同的原因。
