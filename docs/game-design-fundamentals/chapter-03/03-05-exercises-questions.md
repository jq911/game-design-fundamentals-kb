# 3.5 设计练习——习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 3 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：思考题、类别选择、销售平台、玩家预期

## 原书内容整理

为游戏选择一个类别（或决定该游戏不属于任何类别）是定义你的游戏概念的一部分，这个过程会在第7章中详细阐述。当你考虑这方面时，请注意以下几个问题：

#### 1. 提供给玩家的游戏挑战和动作是否符合某一种既定的游戏类别？比如说像驾驶这类游

戏玩家可能会在游戏中花绝大多数时间用到的动作，是不是趋向于放到某种特有的类别中？

#### 2. 如果是通过游戏商店、在线游戏商店或游戏门户网站销售你的游戏，由于这些平台要

求将游戏进行分类，所以这是将你的游戏类别分类的好机会。去雅虎游戏平台（Yahoo! Games）或苹果应用商店看看不同的分类页面，然后考虑你的游戏属于何类。

#### 3. 尝试去向那些你认为是潜在的玩家描述你的游戏，但不能告诉他们该游戏的类别，让他

们来区分该游戏的类别。最后进行确认是不是符合你的预期分类。
