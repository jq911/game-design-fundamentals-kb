# 11.13 设计练习：训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

11.13设计练习——训练

1.游戏作家经常会遇到这种情况，即在信息十分有限的情况下创作游戏剧情，并且不得不尽可

能地写得最好。下面的练习就是在这样的情况下写的一个小剧本，有以下假设场景：一个探险者来到了一个古老的废墟。一个巨大的石头人看守着进入废墟的大门，探险者必须通过确认才能进入。玩家可以使用三种不同的方式处理即将到来的会话：恐吓、赞美、诡计。为这种情况编写一个脚本对话，在每个菜单中玩家可以选择三个选项对应于三种方法中的每一个。如果玩家在整个对话中始终选择相同的方式，石头人会打开大门；否则会遭到石头人的拒绝并且对话终止。

2.这个练习是个案例研究。选择一个你玩过的带剧情的游戏（或者指导老师交给你的游戏）。

依照本章中所介绍的原则分析该游戏，并且写一篇分析报告（报告长度由指导老师来决定）来处理以下几个问题。该游戏的情节是线性的，还是非线性的？如果是非线性的，它用了什么样的剧情结构？它是否有多个结局？它的间隔尺度是剧情故事的叙述方式是什么（多重场景、滚动文本、旁白叙事等）？玩家操作占多大的比例才会对剧情产生显著的影响？考虑所有的玩家操作、游戏内事件和叙述事件，从可信性、连贯性和内涵三方面来综合评判该游戏剧情的质量。该剧情除了引起胜利或失败的情绪外，是否还会引起玩家其他的情绪？如果有，请举例。

3.在书中或电影中选择一个线性故事，写一个半页长度的情节概要（不要以战争与和平开

始）。然后写出在这个剧情中你认为非常重要的几个片段，引入不少于三个分支点的剧情使之成为一个非线性故事——在剧情的分支点处，事件可以朝不同的方向发展，或者游戏角色采取与原剧情描绘所不同的行动。（每个分支点至少存在两个不同的发展方向，如果你愿意多几个也行。）画一个包含所有结果的分解图并且要体现出引入的所有分支选项。

该分解图也要包括原始剧情。写一个简短的总结，展示出在所有分支点上采取不同行动的故事结局。如果你愿意，也可以把所有分支剧情最终汇聚在一起，使最后只有一个结局，或不汇聚让剧情有多个结局。如果剧情中包含多个结局，请确保每个结局都很好地对应每条分支情节。
