# 11.2 关键概念

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

11.2天

在讨论把一个故事放入到游戏中的设计过程之前，我们先介绍一些关键概念，你需要理解这些概念，因为这些概念在我们以后的讨论中会反复出现。

### 11.2.1 故事

最不精确的定义，故事就是一系列事件的记述，不管是历史性的还是虚幻的。在这个基础上，某些人会说每一个游戏都包含一个故事，甚至《俄罗斯方块》也包含故事，因为游戏的动作在以后可以被描述——由观看的人向没有看的人描述。虽然理论上是正确的，但是这种观点对一个游戏设计者来说却没有一点用途。关于《俄罗斯方块》的描述会是一个非常没有意思的故事，因为游戏只是无尽地重复，并且缺乏由玩家的胜利或者失败产生的情感内容。它是非常糟糕的故事以至于不值得讲述。如果我们想把故事结合到游戏中，那么这些故事应该是优秀的故事。

#### 1. 优秀故事的要求

为了把好故事放入游戏中，我们需要拓展原始的定义。那么，一个最低限度可以被接收的故事一定是要可信的、连贯的以及有戏剧意义的。它不应该是反复无趣的，或毫无章法的。

你可以是人类仅存的最后一员，也可以是发明时光机的科学家，但不要同时具备这两个身份。一Ken Perlin，纽约大学教授简单地说，可信就是人们可能会相信这个故事和角色，虽然对于虚构的故事来说，他们必须要暂停某些怀疑才能相信这些故事。很多虚幻和科幻小说，从现实世界的角度来看都不可信，但是一旦读者接受了它们的假设，这些小说就非常令人信服了。然而，即使是幻想或者科幻小说，也一定要给观众提供可以同情、认可或者认为令人信服的角色。如果一个角色是不可信的，那么这个故事就是有缺陷的。幽默的故事不必像严肃的故事那样可信。不同的观众可以忍受不同的可信度，所以你应该在不同的人身上测试你的游戏来看看他们是否认为你的游戏可信。

连贯的意思是这些事件不应该不切题或者是任意的，而是应该和谐地创造一个满意的整体。即使某些事件间没有因果关系或者某些事件只是为了锦上添花，所有的事件应该仍然属于这个故事。一个关于阿波罗太空计划的故事如果包含了公元1世纪罗马人入侵犹太的事情就不连贯了，因为罗马人入侵犹太跟阿波罗计划没有任何联系。另一方面，如果阿波罗计划的故事包含了伽利略建造天文望远镜的场景，那么就会很和谐，因为他使用望远镜观察天空是天文学上一个重要的里程碑，这也最终推动了月球登陆。

任意或看似随机的内容破坏了连贯性和可信度。一些作家可以随意插入不属于前文描述过的事物，如果他们想做一个超现实主义或荒诞故事的话。这种做法需要非常大的手腕，在电子游戏行业中极其罕见。如果你在游戏中包含了任意事件，那你的玩家很可能会把它理解为废话。

重复会伤害玩家对某一个故事的沉浸感，尤其对现代人来说。如果你创作了一个故事，其中写到一个侦探必须分四次去敲一个证人房间的门，才能发现有人在家，那读者会在第二次或第三次这样做之后感到无聊。即使你的故事是真实事件的记录，你通常会通过写作来缩小这些访问，“他在找到任何人之前必须访问几次。”这个过程称为戏剧性压缩。孩子们比成年人更容忍故事中的重复，因为他们仍然在学习如何预测行动的后果。

为了有戏剧意义，故事的事件必须涉及听众关心的某些东西，最好是某些人。故事必须通过这种方式构建以让听众认可故事中的一个或者多个角色。当游戏讲述故事的时候，作家必须非常详细地计划这些有戏剧意义的事件，否则玩家很自然地会从玩游戏的过程中跳出来。不管使用哪种方式，所有的事件都应该通过玩家对角色的认可以及对发生在他们身上的事情感兴趣来帮助玩家投人到故事中。见11.2.3节。

一个优秀故事的最低限度是对那些有戏剧意义事件的可信而连贯的记述。

#### 2. 交互式故事

为了定义交互式故事，我们要重新回顾一下要点中给出的优秀故事的定义。记述（account）暗示了这些事件是过去发生的，这也是为什么故事（即使那些以未来为背景的）

通常都使用过去时的原因。另一方面，交互式故事发生在现在，和玩家一起处在一系列事件之中，通过这些事件前进。而且，玩家的动作形成了故事本身的一部分，这就使交互式故事与被动地呈现给听众的故事有非常大的不同。事实上，一个交互式故事包含了三种事件：

- 玩家事件（player event）：玩家直接执行的动作。除了可以给玩家提供作为可玩性

的一部分来执行的动作一用来克服挑战的动作一你也可以向玩家提供作为故事的一部分来执行的动作。例如，角色扮演游戏中和其他角色交谈，可以看作是为故事的需要服务的，而克服挑战则不要求这些动作。如果玩家的动作可以影响故事情节并改变它的未来，我们就称为戏剧性动作（dramatic action）。然而，有些玩家的动作不是戏剧性的，他们的目标是克服挑战而不影响情节。

- 游戏内事件（in-game event）：就是发起游戏核心机制的那些事件。这些事件可能会

对玩家的动作有一定的反应（例如，当玩家踩住一块特定的石头时陷就会打开）或者独立于玩家的动作（例如，一个模拟的卫兵检查城堡的大门是否被锁住了）。

玩家也可以故意地引起这些事件发生，或者改变它们发生的方式，或者完全阻止它们发生——这就是使故事具有交互性的一部分。

- 叙事性事件（narrative event）：这一部分内容是玩家不能改变的，虽然玩家可以决

定它们是否发生。一个叙事性事件向玩家讲述某些动作，玩家不能和它交互。叙事性事件将在本书的11.2.2节中专门讲述。

记住上述内容，下面我们提供了交互式故事的正式定义。交互式故事（interactive story）就是玩家通过执行动作与之进行交互的故事。如果玩家的动作不能改变情节的方向，故事也可以是交互式的。

交互式动作的定义和我们很多同行的定义都不同，他们一般认为如果玩家的动作不能改变情节的方向（即情节是线性的），那么故事就不是交互的，改变玩家剧情线的走向，同时也可能改变未来事件的力量——称为代理。一些设计师认为，如果一个故事的游戏不提供玩家代理，它不能说是真正的互动。这是一个误解，因为它忽略了玩家自己的行为在形成她的游戏体验中的作用。即使玩家的动作没有改变未来的事件，仍然可以感觉到他在和故事进行交互。玩家对事件的结果发挥了作用，这也是他们所关心的。

考虑这一种情况：玩家必须找到一种通过保安人员进入建筑物的方式。你可以给玩家几种方法来完成这一点：暴力通过、诡计，或耐心等待直到保安人员转移。无论玩家选择哪种方法，他仍然通过同一个门进入建筑，并在另一边遇到相同的东西。如果他的决定没有真正影响故事的未来事件，则他没有代理。但他关于如何通过门的决定有助于情节，他自己的行动是他游戏经验的一部分。这一个故事是线性的，同时仍然是互动的。

变的故事之间的区别。注意，我们的定义中没有说到任何关于量的东西。记住，为了成为一个好故事，一个故事中的事件必须可信、连贯并且有戏剧意义。玩家的动作结合在一起就是故事中的事件，所有这些动作越是能组成可信、连贯和有戏剧意义的事件，这个故事就越优秀。即使一个动作不是戏剧性动作（即影响情节的动作，我们前面讲过），也可以有戏剧意义。换句话说，它可以是玩家关心的某些事情。当设计交互式故事时，你不应该让玩家做那些并不可信地属于故事中的事情，那样结果也不会连贯。就像在《侠盗猎车手》系列游戏中，玩家不能为无家可归的流浪汉们捐款；在《警察故事》系列游戏中，玩家不能偷车一样。

在大部分有交互式故事的游戏中，玩家的动作随着情节移动化身。当玩家克服一个挑战后，游戏用故事中的下一个事件作为响应。如果玩家没有克服一个挑战，那么故事要么到达一个不成熟的结局（然后，它就会说，化身在一次尝试中死亡了），要么就是简单地不能向前推进——玩家直到克服了特定的障碍才能看见未来的故事事件。然而，这种安排也有例外。在某些游戏中，不论玩家是否克服了游戏的挑战，故事都会继续向前推进。我们会在11.7节中详细讨论这个问题。

### 11.2.2 叙事

叙事的定义本身就存在很多争议，在本书中我们使用一个与故事叙述理论家使用的非常相近的定义。叙事由叙述动作产生的文本或者谈话组成。在交互式故事中，叙事是设计师向玩家讲述故事的一部分，它和玩家执行的动作相反，也和核心机制创造的事件相反。

叙事（narrative）指的是叙述出来的故事事件——它由游戏告诉或者展示给玩家。叙事由故事的非交互式、表现型部分组成。

#### 1. 叙事的作用

电子游戏中叙事的主要作用就是把那些玩家不能控制的事件呈现给他们。通常这些事件都发生在化身身上且玩家又不能阻止的事件或是在化身不在场时发生的，但我们仍然希望玩家看到或者知道的事件。通常叙事主要用来描绘成功或失败的场面。

如果你希望的话，叙事也允许你向玩家展示游戏的序言。它不仅向玩家介绍游戏中的情况（游戏的主要挑战），而且还向玩家介绍游戏世界本身。好比一个足球游戏的启动画面显示的是一位球员奔向球场，那么这就是一个叙事性事件，而且玩家不能改变。有时这种序言只是文字性的。虽然游戏的视觉和声音——图像和音频——创造了游戏世界物理具体形象（这个世界看起来是什么样的），但它们不能解释这个世界的历史和文化（它为什么看起来这样）。如果你没有设计那些文化和历史，那么游戏世界感觉就像一个主题公园：游戏机制之上的所有虚假的外表和稀疏的装饰。为了建立丰富感和深度感，你必须创建一个背景，而且某些背景可以通过叙事表现出来。

叙事常常可以作为一个奖励，当玩家实现了游戏的主要目标之后，他可以看到一个过场动画或读到更多的有关他所玩游戏的故事。不喜欢游戏故事的玩家通常会忽略掉这些叙事时刻，但许多玩家却非常喜欢它们。

#### 2. 共同使用的叙事块

很多电子游戏使用叙事资料块（非交互式内容的简短情节）来讲述故事的某个部分。在游戏开始的时候设计师们共同使用一个叙事块来作为一个介绍这个故事的开幕插曲，或者在玩家完成游戏的时候作为这个包装好故事的结尾情节，它经常采用一种简短的说明介绍玩家会在下一关（章节或者任务）中遇到的情节形式，或者采用场景插叙（cut-scenes）的形式，就是在玩游戏过程中呈现给玩家的暂时打断游戏的短小的非交互式情节。

例如，游戏《半条命》就以一个电影片段开始，电影片段中，玩家的化身戈登·弗里曼驾驶着一辆有轨电车穿过Black Mesa联合研究所，同时有一个声音解释他为什么在那里。

这个开幕插曲介绍了游戏世界，并且设置了后面玩家要体验的舞台。关卡之间出现的叙事块一般会持续30秒到4分钟或5分钟的时间。游戏开始和结束时的叙事块有时会比较长，因为它们向整个游戏体验提供了重要的叙事支撑。在《光晕2》中，叙事场景的时长就超过了5分钟。

另一方面，游戏过程中的场景插叙应该简短，因为它们打断了玩家动作的流畅和节奏。对于那些喜欢快速移动类别游戏的玩家，像实时策略游戏或者动作冒险游戏的玩家，如果你让他们听或者观看的时间过长，而不让做些事情，他们就会感到厌烦。像冒险游戏或者角色扮演游戏这些移动较慢的游戏的玩家可以更好地忍受长时间的场景插叙。

#### 设计点拨：非交互性情节一定可以被中断

所有的叙事材料应该都可以被玩家中断。提供一个允许玩家跳过这些情节的按键，使他们可以继续后面的游戏，即使这个情节中包含了玩家想要获胜必须要知道的信息。一个不是第一次玩这个游戏的玩家已经知道了叙事中包含的内容。

#### 3. 叙事的形式

电子游戏中的叙事有很多种形式。一个预先制作好的电影、利用图像引擎显示的一个场景插叙、介绍任务的滚动文本、解释游戏背景故事的画外音，甚至是一个角色的长独白都可以认为是游戏的叙事元素。

叙事，因为在对话播放的时候玩家不能改变它。然而，游戏中的对话经常发生在一个上下文环境中，玩家选择她的角色要说的话，然后游戏根据玩家化身所说的内容，选择一个合适的回复。因此，我们认为这种交互式的对话不是叙事。另一方面，NPC之间的长的、非交互式的对话可以认为是叙事。

#### 4. 平衡叙事和游戏可玩性

由于玩游戏是一个主动的过程，而观看一段叙事是一个被动的过程，因此玩家会注意到它们之间的不同。像《暴风勇士》这样简单的街机游戏没有呈现任何叙事内容——它只具有游戏可玩性。一本小说或者部电影没有提供任何游戏可玩性——一它只具有叙事性。

游戏中包含的叙事越多，玩家就只能观看你的故事，其他什么都干不了的时间越多。但是玩家玩游戏不是为了看电影，他们玩游戏是为了行动。任何包含叙事元素的游戏都应该在玩家行动的欲望和叙事的需要之间找到平衡。如果你提供过多的叙事且过少的游戏可玩性，那么玩家就会觉得你的游戏不值得他们花费那么多钱。玩家花钱是为了将他们的幻想付诸行动。如果游戏中的大部分内容都是非交互式的，他们就会感觉被骗了——他们没有得到花钱希望得到的体验。

太多的叙事也会让人感到游戏好像是按照既定的方向前进的，玩家的动作只是把游戏向预定的结果进行移动。除非你编写一个多结局的游戏，否则结局就是预定的，但是你又希望让玩家感到他们是在主动地参与到故事中。当设计者采用过多的讲述时，玩家就会感觉他好像被牵着鼻子走。他没有按照自己的方式玩游戏的自由，不能创造自己的体验。

#### 设计点拨：避免夺取对化身的控制

当你创造游戏的叙事片段时，要尽量避免夺取对玩家化身的控制。在很多的游戏中，叙事会突然控制玩家化身，并且让化身卷入一场战斗，或者陷入不必要的危险地带，或者干脆说一些玩家完全不可能说的蠢话。改变化身周围的世界作为对玩家动作的回应是公平的，但是从玩家那里得到化身的控制权就不是那么公正了。

所有计算机游戏存在的理由都是交互式的活动：给玩家一些可以做的事情。这里的技巧就是提供足够多的叙事来丰富游戏世界并给玩家提供动机，但又不能过多，不能抑制玩家用他自己选择的任何方式克服游戏挑战的自由。回想一下《指环王》中巫师甘道夫说过的一段话：“我们不能选择生存的年代，所有可以决定的就是怎样利用这个赋予给我们的年代。”玩家不能决定他玩游戏所处的世界，那是由你确定的。但是他必须有在那个世界中行动的自由，否则就谈不上玩游戏了。

### 11.2.3 戏剧性紧张和游戏可玩性紧张

很多设计师都被两个表面上很相似的概念迷惑了，那就是：戏剧性紧张和游戏可玩性紧张。这里我们将会定义这些术语，并探讨它们在娱乐玩家方面的作用，解释你为什么不应该混淆它们。

#### 1. 戏剧性紧张

当一个读者阅读（或者观察者观看）一个故事时，她会感到戏剧性紧张（dramatictension），就是那种某些重要的事情处于危险之中的感觉，还夹杂着想知道接下来会发生什么的欲望（编剧家把它称为冲突，但是由于我们使用冲突来说明游戏中敌对力量的对立，所以更喜欢使用戏剧性紧张，因为它更适合所有的情况）。戏剧性紧张是故事进行讲述的本质，不管是通过什么媒体进行讲述的。悬念——书籍的章节或者电视剧某集结尾处的刺激状况——提升了观众戏剧性紧张的感觉并且可以保证他们会看到这种状况得到解决。在一个故事的高潮点，各种行动都会改变方向，所以这时紧张程度就会开始下降，而不是增长。

#### 2. 游戏可玩性紧张

当一个玩家玩游戏的时候，他会感觉到游戏可玩性紧张（gameplaytension），也是那种某些重要的事情处于危险之中的感觉，和想知道接下来会发生什么的欲望。但是游戏可玩性紧张和戏剧性紧张的来源不同，它来自于玩家战胜挑战的欲望以及是否会成功或者失败的不确定性。在多玩家游戏中，玩家不知道他的对手接下来会干什么的不确定性也会创造游戏可玩性紧张。

#### 3. 错误的类似

游戏设计师容易认识到戏剧性紧张和游戏可玩性紧张很类似，就像这两个术语简单地说明同一种感觉。然而，这种类似是错误的。戏剧性紧张依赖于读者对一个角色（或者几个角色）的认同和对那个角色接下来会发生什么的好奇心。游戏可玩性紧张不要求任何角色，一个飞镖玩家在猜想他是否能够击中靶心的过程中会感到游戏可玩性紧张，但是这种情形只有在一个故事上下文中的结果关系到了一个角色时才能提供戏剧性紧张。

戏剧性紧张和游戏可玩性紧张一个重要的区别就是它们在面对随机性和重复性时这种感觉持续的能力，我们将在11.2.1节中进行介绍。

对戏剧性主题感兴趣的读者在遇到随机性和重复性时戏剧性紧张会消褪。另一方面，游戏可玩性紧张可以很容易更长时间地忍受随机性和重复性。但是扑克牌和《俄罗斯方块》不仅具有很强的随机性，而且还大量重复，却仍然具有很高的游戏可玩性紧张。

思考下面的对话，它摘自英国科幻电视喜剧《红矮星号》。一天晚上，阿诺德·瑞默和他的室友戴夫·利斯特坐在一起，并向他详细叙述他10年前玩的《征服世界》游戏的每一个细节。利斯特多次让他停止，而瑞默却不能理解为什么。

瑞默：但是我想这是因为我还没有讲到真正有意思的地方。利斯特：什么是真正有意思的地方？瑞默：嗯………那是两个小时之后，在他扔了一个3和一个2之后，我扔了一个4和一个1。我拿起了骰子.利斯特：打住吧，瑞默，打住真正有意思的地方和无聊的地方一模一样。

瑞默：可是你不知道我对那个骰子做了什么，不是吗？我把这些骰子塞进他的鼻孔，对着他的鼻子打下去，然后它们就从它的耳朵中冲出来了。这应该非常有意思吧！

利斯特：好吧，瑞默，你对骰子做了什么？瑞默：我扔了一个5和一个2。利斯特：那就是真正有意思的地方？

瑞默：是啊，它对我来说非常有趣，它把我带到了伊尔库茨克?。一《红矮星号》系列第4季，第6集“彻底垮台”

这段对话中有两行清楚地说明了这一点。利斯特说：“真正有意思的地方和无聊的地方俄罗斯城市。——译者注一模一样。”后来瑞默说：“它对我来说非常有趣，它把我带到了伊尔库茨克。”与《俄罗斯方块》一样，《Risk》充满了重复和随机性。瑞默认为这很有趣是因为他把游戏可玩性紧张——我会征服伊尔库茨克吗？一同戏剧性紧张弄混淆了。

#### 设计点拨：随机性和重复性会摧毁戏剧性紧张

即使游戏本身是重复的，游戏中的叙事事件也一定不能随机或者任意地发生，叙事本身也不能重复。
