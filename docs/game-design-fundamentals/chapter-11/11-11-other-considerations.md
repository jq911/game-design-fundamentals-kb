# 11.11 其他需要考虑的事项

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

本节我们通过讲述受挫作家综合征和插话式发布来结束对交互式故事的讨论，还包含了一些游戏行业在未来将如何讲故事的思考。

### 11.11.1 受挫作家综合征

那些实际上更适合于从事非交互式媒体一如电影导演——的游戏设计者们，当他们在编写非交互式故事时，经常会犯两个关键的错误。首先，他们更容易编写线性故事，当向自己和玩家假设故事可以提供更多的戏剧性自由但实际却不是的时候，他们保证玩家具有很大的作用，而实际上根本不是这样的。游戏《关键之路》可以说明这个问题。它的简介中讲述玩家可以获得各种各样刺激的东西，而实际上它的故事保持了如此严格的线性，以至于每一次玩家以任何其他方式背离了故事线，玩家化身就会死亡。（有传言说，开发商使用“CriticalPath”为游戏命名就是为了说明这个缺点。）

当玩家坐下来观看长时间的叙事，而这段时间他们却应该在玩游戏时，他们就会看到第二种受挫作家综合征。《最长的旅程》在其他方面是一款非常优秀的游戏，但是它包含了一段由NPC控制的20分钟的场景独白。即使对莎士比亚来说，那也是一段很长的独白！游戏的设计者，雷格纳·托奎斯特，最初是作为编剧家进行练习的，在这个游戏发行之后也承认这是一个错误。绝对不要忘记玩家是来玩的——是为了做些事情的。几乎任何复杂的故事都要求有一些叙事，但是你必须用合理的长度来安排这些叙事。玩家不想一次花费多于3到4分钟的时间来观看叙事，而且很多玩家都会在3分钟之前就变得很沮丧了。

#### 设计点拨：作一个游戏设计者，而不是一个电影制作者

设计游戏的时候不要向别人展示你作为电影导演或者作家的技巧，设计一个让玩家做些事情来娱乐他们的游戏。一定要给玩家提供比叙事更多的游戏可玩性。玩家是这场秀的明星，而不是故事。

### 11.11.2 插话式发布

到目前为止我们讨论的大部分内容都集中在具有一个明确结局的独立故事上。然而，发行商可能想通过制作一个或者多个结局来开发一个热卖游戏的流行趋势，现在这种情况非常普遍，所以这部分我们讲述故意这样做的设计。游戏行业对这种商业机会产生了极大的兴趣，插话式发布可以提供和向玩家出售几个小时的娱乐，而不是单一的一大块时间，就像零售游戏现在做的那样。

现在主要有三种发布多部分（multipart）故事的形式，在下面的小节中我们将分别讨论。电视产业在发布多部分内容方面比游戏工业更有经验，所有我们将使用熟悉的电视术语来描述它们。

#### 1. 无限制系列剧

“无限制系列剧”（unlimited series）是由许多集组成的，每一集都由一个独立的故事组成，每一集都介绍情节并且解决冲突。一个单一的主题或者上下文背景贯穿整个系列剧中但是没有个单一的情节；实际上，故事彼此之间的存在是如此独立，以至于按照任意的顺序观看这些集同样有意义。从20世纪80年代开始美国晚间电视剧几乎就专门使用这种形式：在《神探可伦坡》的每一集中，可伦坡严密地解决每一起犯罪行为。每一集几为每一集都提供一个独立的故事，所以制作商可以创建希望的任何数目的剧集（如图11-6所示）。

大部分游戏和它们的续集都使用无限制系列剧形式。系列中的每一个游戏都包含一个设置在统一的世界中的独立故事。有时候发行资料声称续集延续了上一个游戏的故事，但是通常它们之间的关联非常松散。在任何情况下玩家都会得到一个完整的介绍，所以即使他没有玩过上一个游戏，仍然可以享受当前的游戏。

#### 2. 连续剧

“连续剧”（serial）理论上由无穷多集的序列组成。在连续剧中，情节线延伸到许多集剧情中，它们按照不同的速度同步发展，但是几乎没有任何情节的开始和结束都在一集的剧情中。结果就是这些剧集不是独立的，如果你观看了单独的一集而没有看前面的，那么你就不知道当前正在发生什么。为了保持玩家的兴趣，每一集都在主情节线的一个关键点处结束，创建一个悬念，作家希望通过它营造出观看下一集的强烈欲望。肥皂剧就依靠这种格式。

连续剧依靠很多角色分成不同的小组聚集在一起，每一组角色演出多个不同情节线（通常它们互相没有联系）中的一个，其中每一个都可能在任何时间开始、达到高潮或者结束。由于没有全局的情节，所以这些事件通常以特定位置的一组人或者家庭中的一组人为中心。连续剧缺乏英雄路程所提供的那种解决问题的盛大的感觉。它们给观众提供了观察处于各种压力之下相互影响的一群角色的机会。每一集结尾处留下的悬念可能会涉及某些令人震惊的新发现或者事件，它们会让我们想知道一个关键的角色对这种新闻或者环境的改变会做出怎样的反应。

#### 3. 有限制系列剧

“有限制系列剧”（limited series）包含了无限制系列剧和连续剧的特征。有限制系列剧通常把一个单集的情节线（即开始和解决方案都在一集范围内）和跨越了许多集的情节线组合起来。然而，与无限制系列剧和连续剧不同，有限制系列剧也保持了一个贯穿所有集的全局情节线，它最后会产生一个确定的结局，这就使这个系列剧变得有限了。《巴比伦5号》就是一个有限制系列剧，而《肯塔基0号路》则是电子游戏中的例子。

#### 4. 插话式发布的潜力和限制

游戏行业已经使用无限制系列剧格式制作游戏了，我们相信它也会开始使用有限制系列剧的格式制作游戏，来鼓励玩家购买整个系列。利用有限制系列剧形式开发游戏将会要求更多的资金和计划，如果开发商确定这个游戏将会成功，那么这还是值得做的。《哈利·波特》系列游戏，在书籍和电影的基础上，大概会成为一个有限制系列剧：当全局故事结束时，游戏系列就会像作者计划的书籍系列那样结束。技术更新的速度可能会成为一个问题，在后来的游戏中，可能不能使用早期游戏的过期代码。在系列的中期重新编写代码将抵消掉在早期计划整个系列产生的节省成本。如果游戏产业可以找到一种快速并且廉价地在连续的基础上制作内容的方式，那么我们最终就会看到交互式连续剧，没有固定的集数，没有一个逐渐展开的故事。在互联网上通过浏览器运行这样的游戏是最好的方式，因为与独立的游戏相比，网络提供了更便宜的开发和发布成本。如果我们的预言是正确的，发行商在网络上开发限制系列剧游戏，然后为了盈利，那些游戏可能会使用基于广告的商业模式。很少有玩家会为基于网页的游戏付费因为存在很多免费的游戏。

当前，大部分努力都集中在开发一个持续的基础的内容上，这个持续的基础涉及“永online game，MMOG），而不是插话式发布系列。MMOG使用订阅的商业模式，一旦经营者收回了设计游戏所需要的非常高的投资，那么他们就可以大量盈利了。

如果你正在开发一款PC游戏或者控制器游戏，我们推荐你不要故意把故事留着不结束。当玩家玩了很长时间之后，发现需要购买另一款游戏才能找到故事的结局，他们会非常失望，那些极个别使用这种方法的游戏也充斥着批评。一个长的游戏在结束的时候应该解决它的主要问题，不管是好还是坏。如果你为了一个续集而离开一个房间，那么这个续集应该是与第一个故事中出现的问题不同的一个问题。《星球大战IV：新希望》就是一个完美的例子：故事结束的时候英雄摧毁了死星（电影的主要问题），但是达斯·维德（故事中引入的一个角色）却逃跑了，这样问题就依然存在。《星际争霸》中故事结束的时候摧毁了主宰（Overmind，它的主要问题），但是莎拉·凯瑞甘，一个关键的角色，却明显变成了一个背叛者，她领导一个背叛的集团跟第一个故事中的英雄作对。除非你的故事是一个多部分故事的一部分，你可以保证所有的部分最后都会讲述，否则玩家在游戏的结尾时都应该看到解决方法一尤其是对于一个很长的游戏来说。《质量效应3》中令人不爽的结局就引起了大多数玩家的愤怒，以至于它的开发公司BioWare不得不针对玩家的诉求，发布免费的扩展包。
