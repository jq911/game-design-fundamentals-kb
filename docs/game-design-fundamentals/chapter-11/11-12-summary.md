# 11.12 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

大部分电子游戏都会从加入的故事中受益，这个故事应该是一个可信的连贯的和有戏剧意义的故事。然而，设计者在设计电子游戏故事的时候应该避免编写电影或者小说，他应该记住交互性是人们玩游戏的原因。不管你决定为游戏制作一个线性的、非线性的还是一个反送的、多结局的故事，它们都依赖在概念设计阶段设计的游戏可玩性和游戏类别。

为了让玩家在完成游戏时获得更大的满足感，设计师应该制作一个好的故事来保持玩家的兴趣。这个好的故事应该展示出玩家的成长、叙事元素的平衡和游戏可玩性，并且最重要的是，保持游戏玩起来很有趣。
