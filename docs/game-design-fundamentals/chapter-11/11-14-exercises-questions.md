# 11.14 设计练习：习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

11.1.2节中有一个“如何为你的故事写一个需求规范”部分，以下这些问题实际是它

的缩略版。

1.如何设置玩家在游戏剧情中的行动才能让剧情可信度好、情节连贯、内涵丰富？

2.怎样设计你的游戏可玩性，让玩家不经历太多随机或重复剧情，从而减少对故事情节戏

剧张力的影响？

3.你的游戏剧情是线性的还是非线性的？

4.如果剧情是非线性的，你会让剧情产生多个结局还是单一结局？什么类型的事件会导致

剧情出现分支：挑战、选择或两者都有？是否允许延迟影响或累积影响的情况，还是希望选项的影响及时反馈？

5.如果所有分支剧情最终汇聚，会发生多少不可避免的事件？它们是什么样的事件？

6.你的剧情最终会产生多少个结局？每个结局是如何体现玩家在整个游戏中的行动或选择的？

7.游戏间隔尺度的大小是什么？什么时机将叙述事件与游戏事件和玩家行动交织在一起，怎么

交织？

8.你会用什么方式推进情节的发展？旅行、事件、时间，还是几种相结合？

9.剧情是随着游戏的开始而开始好，还是在一段开场白之后开始好？

10.游戏中是否包含叙述性材料？它在游戏中有何用途——介绍、任务简介、过渡性材料、

总结，或者角色定义？这些叙述对于玩家理解和体验游戏是否是必要的？

11.对叙述材料采取什么样的形式？翻页手册形式？滚动文本形式？电影形式？多重场景形

式？旁白叙事形式？角色独白形式？

12.玩家的哪些行动是和剧情发展相关联的，但又与关卡挑战无关？对话？生产建设？

探索？

13.游戏中是否包含对话文本？它们是处于玩家和哪个角色之间的吗？它们的意图是什么？

14.剧情是否由几个部分组成？如果是的，如何处理情节线索：作为一个无限制系列、还是

有限制系列，还是连载系列？
