# 第 11 章 故事讲述和叙事

## 本章定位

本章讨论电子游戏如何讲述故事，以及故事、叙事、游戏可玩性之间如何配合。重点关注交互式故事、故事讲述引擎、线性与非线性结构、对话树、情节推进机制，以及在不压过玩家行动的前提下组织叙事内容。

## 复习线索

- 故事应当可信、连贯，并具有戏剧意义，但游戏仍应以玩家行动为中心。
- 交互式故事由玩家事件、游戏内事件和叙事性事件共同构成，故事讲述引擎负责把叙事事件交织进游戏流程。
- 线性故事、分支故事、反送故事和自发叙事各有成本、自由度和情感控制上的取舍。
- 情节推进可以依靠挑战、选择、旅行或时间流逝；叙事间隔尺度会影响玩家感到故事与玩法是否无缝。
- 带脚本的对话和对话树能在不解决自然语言理解难题的情况下，为 NPC 互动提供可控的叙事结构。
