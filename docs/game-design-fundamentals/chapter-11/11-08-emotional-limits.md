# 11.8 交互式故事的情感限制

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

那些不包含故事的电子游戏——也就是主要通过游戏可玩性的挑战和成就达到娱乐效果的游戏——不会试着唤起观众的复杂情感。他们把自己限制在胜利的激动和被打败的苦恼中，或者还有被重复打败的沮丧。但是使用一个故事，可以创造出其他的感觉。通过塑造观众关注的角色和那些角色之间的微妙关系，你有机会让观众感觉到（和角色的感觉一致）爱人的背叛，对完成正义的满足或者对一个孩子本能的保护。

然而，交互式媒体的本质却对你能做的事情强加了一些限制。在这一节中，我们将了解一下非线性故事和基于化身的交互模型的情感限制。

### 11.8.1 非线性故事的情感限制

当你在讲述一个非线性故事时，你就赋予了玩家可以做出那些影响角色之间关系的重要选择的自由，这也会包含一些情感上感到错误的决定——或者至少不符合故事讲述者希望玩家所做的事情。假如你在讲述以莎士比亚的著作《哈姆雷特》为基础的故事，你给了玩家可以控制哈姆雷特的很多选项。但是在原著中，哈姆雷特发现了自己的母亲和叔叔的阴谋篡位，是他们谋害了自己的父亲——丹麦国王。随后哈姆雷特父亲的灵魂出现在他面前，并且要他为自己报仇，但哈姆雷特却犹疑不定。

当到了游戏当中，玩家自己扮演哈姆雷特，他可以简单地逃出这种情况并且永远不回来；也可以直接无视他父亲的灵魂，并且宽恕他的母亲和叔叔；或者试着暗杀他的叔叔然后自己戴上王冠；或者干脆自杀。这些结局中没有一个能像莎士比亚实际写的那样有趣。

事实上，某些玩家可能会把故事带人一个冷漠的不能令人满意的结局中。通过给玩家提供改变故事过程的力量——或者至少改变结局——你就同意了玩家的决定，甚至不符合一般故事讲述原则的决定。你不能保证玩家可以体验到故事中提供的情感上最强大的解决方案，除非你把玩家限制在一个单一的解决方案中（即使这样，由于个人品位的不同，玩家也可能更喜欢一个不同的结局）。

设计者通常把非线性故事限制在一个单一的结局里，这样只是为了保证玩家能够体验到设计者计划的最具有情感意义的结局。也就是说玩家在到达结局之前的戏剧上的自由都只是一种假象，只要你没有向玩家保证他们的选择会改变结局，但实际上一开始就确定的结局，玩家就可以忍受这种假象来换取一个令人满意的结局。

体要求新的规则。一定要警惕将其他形式的原理（例如亚里士多德的戏剧原理或者罗伯特·麦基的关于电影剧本创作的观察资料）不假思索地应用到交互式故事中。

如果它不适合你，就放弃它。

### 11.8.2 基于化身的游戏的情感限制

基于化身的游戏和用第一人称写的故事很相似。因为我们假设一个第一人称故事的叙述者是活着的，所以听众知道不管故事中发生了什么，叙述者都必须存活下来以便在后来写这个故事。这并不是绝对的——小说《权力的游戏》中的叙述者就经常性地死去，然后换成新的叙事者来继续讲述故事。这不仅限于第一人称小说，相似的限制也适用于基于化身的游戏。因为化身通常在一开始的时候有好几条命，玩家知道一个化身应该可以存活到游戏的结尾。游戏中，化身的过早死亡表示玩家挑战的失败而不是故事中一个真实的元素，因此化身的死亡几乎不会带来任何情感冲击。玩家只是重新载入游戏然后再玩一遍而已。

如果你真希望通过一个角色的死亡来影响玩家的感情，那么你的游戏就应该杀死化身身边的一个朋友而不是化身。游戏《星球坠落》和《最终幻想VI》就是两个著名的例子。在《星球坠落》中，玩家的同伴，一个说俏皮话的机器人，在一个关键的地方为了让玩家继续前进，牺牲了他自己。玩家经常把这一时刻看作计算机游戏中第一个真正具有情感意义的时刻。在《最终幻想VI》中，坏人杀死了艾瑞丝（玩家的同盟者）。玩家不能做任何事情来阻止它的发生，而且玩家经常提到这次死亡，把它作为游戏中特殊的情感时刻。

同基于化身的游戏相比，基于团队的交互模式可以提供更多的自由用来杀死团队中的一个成员，因为团队中其他成员仍然可以使故事继续。两个不同的电视剧就可以作为很好的例子。《亡命天涯》中的成员就不能忍受金波医生的死亡，因为他是这部电视剧的英雄——等价于基于化身的游戏中的化身。另一方面，关于纽约侦探和检举人的长篇电视剧《法律与秩序》系列，就是一部全体演出者的电视剧，而不是关于一个英雄的。在它播放的这些年里，演员表随着一个又一个演员的加入和离去而不断地改变。这部电视剧能够持续运行是因为它的中心假定不依赖于任何个人。
