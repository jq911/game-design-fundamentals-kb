# 11.6 间隔尺度

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 11 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。

## 原书内容整理

在讲述故事的游戏的上下文中，“间隔尺度”（granularity）指的是游戏向玩家呈现叙事元素的频率。例如《星际争霸》是在执行所有可用的30个任务的过程中讲述了一个很长的故事的游戏（以故事中主要角色对话的形式来展现），但是它只在两个任务之间呈现叙事。

因为每个任务要花费二十分钟到一个多小时不等的时间才能完成，所以这个游戏呈现的叙事块非常不频繁，我们可以说《星际争霸》中的故事讲述展示出很大的间隔尺度。《银河飞将》系列游戏也在任务之间讲述一个故事，而且也表现出很大的间隔尺度。

卢卡斯艺术工作室的冒险游戏——《猴岛的秘密》和《夺宝奇兵》系列一会在玩家每次解决一个谜题的时候都提供给她少量的叙事。它发生的频率为4到5分钟一次，所以这些游戏中的故事讲述表现出小的间隔尺度。LucasArts的游戏也使用了比较短的叙事块，通常使用场景插叙或者语音说明的形式。

对于什么是小的或者大的间隔尺度没有一个固定的标准。你会发现在比较两个游戏的相对间隔尺度时这个术语才有用。

理论上，一个游戏中的故事讲述可以有无穷小的间隔尺度——那就是说，游戏可玩性和带有合适的间隔尺度的故事讲述以一种细微的方式进行交织，以至于使玩家意识不到叙事事件是和游戏中的其他部分独立的，他们看到的游戏一个无缝的交互式体验。游戏开发者通过长时间的尝试，在交互式故事讲述上不同程度地达到了这种要求。一般情况下，如观看的其他故事事件，那么这个游戏就非常接近这个目标。

注意不同的作者使用间隔尺度来说明不同的游戏设计概念：玩家采取动作的频率、游戏通过得分值反应玩家成就的程度等。由于这种模糊性，除了谈到交互性故事讲述的时候，我们尽量避免使用这些术语。
