# 6.3 世界游戏市场

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 6 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：世界市场、传统市场、新兴市场、本地化、文化限制

## 原书内容整理

电子游戏在整个世界范围内受到喜爱的程度正在增加，但是不同的地区喜欢不同的东西同时花费金钱的数目也不同。在本节，我们将简短地介绍一下各种各样的世界游戏市场，其中包括了传统的游戏市场和新兴的游戏市场。
