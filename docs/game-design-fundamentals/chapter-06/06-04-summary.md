# 6.4 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 6 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：总结、盈利模式、销售地区、设计影响、游戏理念

## 原书内容整理

这一章并不是告诉你如何设计游戏，而是展示了通过设计游戏盈利的方式以及在哪个地区销售你的游戏会影响你的设计思路。你现在了解了一些关于传统直接销售模式和新的间接销售模式。你也学到了世界上哪些市场是庞大、稳定的，哪些市场正在成长中，不管是快还是慢。这些信息将会帮助你构建你的游戏理念，这也是下一章要讨论的主题。
