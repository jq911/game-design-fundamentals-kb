# 6.5 设计练习——习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 6 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：习题、资金来源、推广计划、盈利方式、市场选择

## 原书内容整理

#### 1. 谁会为你的游戏制作提供资金，出版商、投资者、客户、你自己，还是其他人？你期望

这个关系对你的设计决定产生怎样的影响（如果不是你自己）？

#### 2. 谁会推广你的游戏？如果答案是“我自己”，你这样做的计划是什么？你将如何在这个计

划上分配资源（钱和职员）？

#### 3. 你希望如何通过你的游戏盈利，通过一种直接的销售模式还是一种间接的销售模式？

#### 4. 如果对问题3中的回答是直接销售模式，那么是其中的哪一种？如果你计划使用基于订

购的模式或者章节销售模式，你有没有制作这种定期更新的游戏的资源？

#### 5. 如果对问题3中的回答是间接销售模式，那么是其中的哪一种？如果你计划使用免费增

值的销售模式，你有没有想过一些在你游戏中销售的增值项目？

#### 6. 你希望在哪个市场销售自己的游戏？你是否对这个市场的品味和进入市场的障碍有足够

的了解？
