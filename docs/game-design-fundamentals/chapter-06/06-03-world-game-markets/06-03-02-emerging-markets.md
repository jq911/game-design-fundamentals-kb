# 6.3.2 新兴市场

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 6 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：世界市场、传统市场、新兴市场、本地化、文化限制

## 原书内容整理

这些新兴市场是根据今后20年的人口与经济实力的增长评定的。列出这些市场目的是希望在这些地方有更多的人从事游戏行业。

#### 1. 中国

尽管中国不像一些远东国家一样有着发达的经济，但是它的绝对人口数量使它成为了我们需要观察的目标之一。在中国，软件盗版猖獗，所以开发者们开始销售订购模式或者免费增值模式的网络游戏。结果，中国现在贡献出了全世界网络销售盈利份额的三分之一。直到2013年，电子游戏的管控禁止了对青少年教育产生有害影响的内容，在允许的范围内，如果产品将会产生较重大的意义，那么这些内容可以保留。过去很少有中国人会购买私人电脑，所以网吧一度十分流行。中国政府对游戏的态度是十分谨慎地支持，但是会对那些政府或者权威机构批判的任何事情保持怀疑的态度。审查机构是必需的，而且网络防火墙会阻止玩家们进入大部分西方网站，这使得西方游戏公司在那里进行贸易变得更加困难，大多数的网络游戏都是通过中国国家内部制作的服务器运行的。

#### 2. 印度

作为人口仅次于中国的发展中国家，印度是下一个需要作为新兴市场进行观察的国家。然而，除去这些指标，这个国家不太可能快速开发出大量的计算机与控制台游戏用户。除去相似的人口数量以外，印度的计算机数量仅仅是中国的四分之一多一点。在印度，教育十分被重视，这导致许多家长不愿意购买电视。因此，当印度游戏变革到来的时候，很可能就是在手机上。现在，在印度4亿部手机中仅仅只有10%的手机能够玩游戏，但是我们期望这种情况在今后几年内有所转变。印度的中层阶级是使用英语的，这使得为这个市场制作游戏变得更加简单了。然而，印度在社交上是十分保守的（情侣们不能在公众场合接吻），这使得他们能够接受的游戏类型受到了限制。

#### 3. 墨西哥、美洲中部和南美

这个地域对游戏的热情增长很迅速，但是，理所当然，它的人口比上述的两个国家中任何一个国家都少很多。巴西是一个新兴的经济动力地域，墨西哥的电子游戏零售产业比电影和音乐产业联合起来都大，而且还在迅速增长。这个地域的其他国家经常变化，但是除了巴西（巴西的国语是葡萄牙语），其他国家都使用西班牙语，这使得游戏本土化变得更加容易（尽管当地俗语仍然为难着粗心的翻译）。

#### 4. 伊斯兰世界

不可否认，伊斯兰世界的一些地区（沙特阿拉伯、阿联酉）是十分富裕的，能够非常容易地购买电子游戏，同时其他地域（苏丹、巴勒斯坦）的生活条件不是特别好。尽管比印度和中国慢得多，这些市场在将来仍会继续增长。在这里接受电子游戏的主要阻碍就是文化。穆斯林国家没有关于电子游戏的历史，同时也不想要西方制作的游戏。他们的社交方面甚至比印度还要保守，这意味着必须更加小心。注意，不要触犯了当地的敏感问题。与过去相比，大部分的穆斯林国家不再使用阿拉伯语（世界上最大的穆斯林国家是印度尼西亚），但是从非洲北部到伊拉克这部分地区仍然使用阿拉伯语，这使得这些地区的游戏本土化更加容易（这与应用于所有西班牙语国家的本土俗语有着相同的警告）。在其他的方面——不同的文化和体验——伊斯兰国家与欧洲类似，因此游戏的开发十分困难。

#### 5. 撒哈拉沙漠以南的非洲

由于经济和文化问题，这个地域的电子游戏发展放在了最后。这些地区使用数百种不同的语言，游戏本土化将会变得非常困难。还有，他们很少有资金提供给像电子游戏这样的奢侈的娱乐，也没有拥有高科技的历史。南非是一个例外，尽管如此，中产阶层还是没有大到能够代表这个重要市场的全部。
