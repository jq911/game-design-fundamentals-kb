# 6.3.1 传统游戏市场

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 6 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：世界市场、传统市场、新兴市场、本地化、文化限制

## 原书内容整理

毫无疑问，电子游戏的传统市场是在一些发达国家和高科技地域。它们有自己的独特的地方。主要包括了以下几个地区。

#### 1. 英语国家

美国是世界上最大的电子游戏市场，大量的主流游戏——不管它们是在哪里制造都瞄准这一片市场。（日本为他们自己的大型游戏市场制作的游戏是一个值得注意的例外。）美国人喜欢好的结局，他们喜欢看到美德能够受到奖赏。Grim Kafka式的故事并不怎么流行，除了在一些离经叛道的年轻人中间。军事主题的游戏在美国通常也能够卖得很好。作为电子游戏的开发国家，有着如此庞大、多种族组成的人口，几乎任何种类的游戏都能够在这些受众中得到发展。在英国、加拿大——使用英语的地区，以及澳大利亚和新西兰，每个人对游戏通常都有着类似的需求，他们对游戏的类型有着类似的品位。由于这些国家的人口较少，所以市场相对较小。然而，这些市场也倾向于愤世嫉俗，他们认为这种美国市场制作的狂热爱国主义类型的军事游戏相当自以为是。

#### 2. 欧洲大陆

欧洲人对游戏的需求与美国人类似，但是对于游戏的制作要求更高，因为各个国家都有他们自己的语言，同时，他们对游戏的体验也有些变化。许多北欧人（北欧国家与荷兰）更乐于购买英文版本的游戏，因为他们通常在学校中学习英语。然而，最大的市场，其中包括法国与德国，更倾向于玩使用自己国家的语言的游戏。通常，欧洲人比较喜欢暗黑倾向的故事，他们把一些为美国人制作的游戏比作糖精。相比美国人，他们更少地考虑裸露和色情主题的游戏，更多的是暴力。由于德国纳粹党对他们的影响，他们也对那些公然显露的爱国主义表示怀疑。一个叫作欧洲游戏信息的统一标准正在制定，因此玩家们不需要使他们的游戏服从当地国家所认同的标准。然而，德国、芬兰和其他国家仍然保持着他们自己的认证系统。在商业娱乐中，欧洲国家没有自由表达的强烈传统，而许多国家都运行着一套完整的检查制度，尤其是德国，这些制度禁止一切纳粹象征。

#### 3. 日本

日本在电子游戏娱乐国家中是十分独特的。一些最成功的游戏角色和经营特权（Mario、Zelda、Final Fantasy、Metal Gear Solid等）都来自日本，但是这些游戏并没有让带有欧洲品位的游戏有所让步。当然，事实上，欧洲玩家已经对日本游戏表示出欣赏了，相反，日本玩家不玩欧洲游戏。外国游戏公司在日本制作游戏儿乎不可能不包含日本元素。日本有属于他们自己的大型高质量的游戏制作产业，除了刚才提到的风靡全球的游戏之外，日本的游戏产业也制作了许多没有出口的游戏，因为他们考虑到这些游戏太过于日本化而不能够流行。方代起初并不想在西方发布《块魂》，但是由于西方的评论反馈太过积极，所以才改变了主意。恋爱模拟游戏是一种关于恋爱的角色扮演游戏，而不是战斗类型的游戏，这是另一个很少出口到西方国家的游戏的例子。相对于欧洲，日本更能够接受浪漫和明确带色情内容的游戏。

#### 4. 韩国

韩国对游戏的需求并不像日本那么大，作为一个社交上较为保守的国家，色情内容的游戏并不那么受欢迎。韩国游戏的最大特征就是韩国人怎么去玩游戏：在一个公共空间。角色扮演游戏、实时策略类游戏，特别是大型多人联网角色扮演类游戏，在韩国特别流行，他们在PC bang（字面上翻译，计算机房）玩游戏-——一个大型的空间，里面有很多桌子和有局域网的计算机，更像是一个网咖，但是规模更天。相比其他国家，职业化的游戏在韩国更加流行。不管它的年龄，《星际争霸》就是一款十分受欢迎的职业化竞技游戏。
