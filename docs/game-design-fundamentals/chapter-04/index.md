# 第 4 章 了解你的玩家

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，当前已完成初步 OCR 拆分，后续仍建议逐段人工校对并继续完善图表截图。

## 本章定位

本章讨论以玩家为中心的设计视角：玩家动机、人口统计分类、玩家贡献程度，以及避免用二元性思维误判目标玩家的方法。
