# 4.3 玩家贡献

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：玩家贡献、骨灰玩家、休闲玩家、投入度、目标市场

## 原书内容整理

在本书的上一版中，这一部分的名字叫作“骨灰级玩家对比休闲玩家”。但是在过去

的几年里，这个标题慢慢地失去了它的意义。游戏行业中曾对骨灰级玩家、高级玩家和休

闲玩家提出过一个二元区分方式。随着建立在社交网络上的游戏的出现，区分玩家等级的

方式越来明显地呈现出一种连续性，被称为玩家贡献。你可以衡量玩家各个指标的贡献值。

BarryIp和我在论文《从路人玩家到骨灰玩家：研究玩家贡献值的统计机制》（From Casual to Core：A Statistical Mechanism for Studying Gamer Dedication）中列出了这些指标。其中

我们借鉴了ScottKim在游戏开发者大会上的演讲“设计具有商业价值的网络游戏”（Kim，

2001）。虽然这些都是比较老的论文，但内容十分基础，如今仍然可以沿用。

以下是Ip和我提出的15条衡量玩家贡献的指标：

- 对操作技术的领悟力：高度专业的游戏玩家会更加熟悉最新发布的游戏信息，并且

对游戏的相关技术表现出相当大的兴趣。

- 配备最新的高端游戏设备：专业玩家会配备最新的控制器、高端的计算机硬件配置

和移动设备以保持处于游戏发展的最前沿。他们最有可能使用过，或已经获取了各

种各样的老式游戏平台。

- 投入的意愿：专业玩家更热裹于在游戏和游戏周边上投入资金。相反，休闲玩家更

倾向于等待物品打折或者有优惠活动时再决定购买相关设备。

- 更喜欢暴力和动作类游戏：Kim认为骨灰级玩家更希望游戏中出现一定程度的暴力

元素和动作密集的元素。

- 喜欢复杂有深度的游戏：不管是什么样的主题，专业玩家都喜欢挑战难度大的，需

要更长时间通关的游戏。

- 喜欢玩进程比较长的大型游戏：专业玩家更喜欢投入大量的时间玩单章节（关卡）

比较长的游戏。

- 非常渴望了解一切与游戏相关的信息：他们会想尽一切办法了解与游戏相关的信息，

比如了解游戏动态消息、参与游戏论坛的讨论、拜访业内专家，还会通过上网、游

戏杂志和书籍了解游戏攻略。

- 经常和朋友一起在网上探讨游戏：专业玩家热裹于和其他人讨论游戏，还会常去与

游戏相关的网上论坛或者聊天室。

- 对通关游戏的执着：专业玩家永远都很享受通关游戏带来的喜悦感和满足感，并不

会太重视美工上的瑕疵，如人物的造型，琐碎的细节等。

- 更能坦然地承受失败：骨灰级玩家更能接受复杂的游戏，以及挑战中的失败。而休

闲玩家会喜欢一些简单休闲的游戏。

- 在游戏中和自己、游戏关卡，以及其他玩家较劲：骨灰级玩家喜欢通关或者通过提

升自己技能打败其他玩家或计算机对手带来的满足和奖励的感觉。没有哪个专业玩

家是不喜欢这种感觉的，比如说，他们会一次又一次尝试在赛车游戏中缩短单圈时

间的几分之一秒钟，或者在《街头霸王》中花大量的时间耐心地去练习每一种组合

技能，或取得更高的比分。

- 开始玩游戏的年龄：如果有些人在很小的时候就接触游戏，而且之后也经常玩，这

表明他们对游戏更有经验也懂得更多，也更有可能成为专业玩家。而那些接触游戏

晚的人很少能成为专业玩家。

- 对游戏行业比较了解：在游戏领域的专业玩家一般都懂得相对较多，并且比较清楚

游戏行业内的一些活动和发展趋势，还有新技术和游戏开发流程的方法。很少有专

业玩家花很多时间去了解最近发布的信息和游戏的评论，而更多的是关注诸如产业

布局或者融合之类的新闻事件。

- 早期进入游戏：专业玩家会参加半夜抢激活码这类活动，或者用其他的方法在官方

公测之前进入游戏以便更快地把握整个游戏。

- 想要有创意性地修改或拓展游戏：骨灰级玩家经常用不同的方法修改商业游戏。修

改的程度会从改变角色外表的新皮肤到编辑外挂程序。而休闲玩家很少会花时间去

做这些修改。总之，专业玩家更喜欢不按常规的游戏规则玩游戏。

当然，以上任何一个衡量因素所占的份额完全取决于你。原始文献提出这些因素主要

自的是用于研究。而作为一个游戏设计者，你真正需要了解的只是展现玩家贡献程度的方

式。例如，如果你了解了有些专业玩家在收集正在开发中的某款游戏的相关信息，就可以

创建一个开发者博客或者给他们提供推送服务。

现实中，每个游戏都会存在各种各样不同类型的玩家，每个玩家都会有一个玩游戏的

理由。但如果你设计的游戏是专门针对某一类玩家的，就不要试图推销给其他类型的玩家。

当然也有一些可同时吸引专业玩家和休闲玩家的游戏也做得很不错，《黄金眼》就是其中一

款。专业玩家可以选择最高等级难度，然后就会多一个任务，即最后一次挑战时间减少15

秒。对休闲玩家则可以设置最简单的等级，这样就可以享受很顺畅的游戏控制和更多的游

戏细节，《摇滚乐团》也是一个比较好的例子。
