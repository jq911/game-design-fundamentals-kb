# 4.7 设计练习——习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：思考题、目标玩家、年龄区间、性别、投入度

## 原书内容整理

为你的游戏选择目标玩家（你的游戏也可以不属于任何类别）是定义游戏概念的一个

步骤，该过程我们会在第7章中详细讨论。当你在考虑目标玩家选择时，注意以下几个

问题：

#### 1. 你会在自己的游戏中呈现哪些游戏领域，哪些会吸引到你的目标玩家？

#### 2. 你选择的目标玩家年龄在哪个区间？这个问题的答案将会在很大程度上影响到游戏中的

很多东西：它的挑战、它的用户界面设计、游戏进程的步调、美学方面等。

#### 3. 你的游戏是想同时吸引男女两部分玩家，还是只针对某一特定性别的玩家，请记住这样

可能会降低对另外性别玩家的吸引力。如果选择后者，你会选择什么样的游戏内容，如

何呈现你的游戏特征来吸引这部分的玩家？

#### 4. 你希望玩家对你的游戏有一个什么样的投入度？比如说，游戏若需要玩家长时间的投入，

那么这个游戏就不适合那些时间不充裕的玩家，进而就会排除掉这部分玩家。仔细浏览

玩家投入因素的列表，并且问自己是否期待玩家们的投入——如果很期待他们的投入，

那么你计划在游戏中如何满足他们对游戏的期待。
