# 4.4 二元性思维的危害

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：二元性思维、玩家群体、统计分布、包容性、排除性元素

## 原书内容整理

你无法设计出每个人都喜欢玩的游戏，所以你的目标玩家必须是一个特定的群体。特

定群体到底是谁，这也就是问题“谁会喜欢这个游戏”以及“他们喜欢什么样的挑战”的

答案。当你在回答这些问题的时候，就会自然而然地把目标玩家划分到上文提到的某一个

特定分类中（如男人），这个特定分类和其他分类（如女人、儿童、青年等）是没有共同点

的。这就是二元性思维：你假设一个群体喜欢一样东西，那么任何不属于该群体的个体都

不会喜欢这个东西。这是谬论，这种想法会让你失去一部分潜在的客户群，我们在下面来

解释这个问题。
