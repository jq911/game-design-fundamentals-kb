# 4.5 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：总结、玩家领域、人口统计、贡献程度、包容性

## 原书内容整理

本章主要是帮助大家了解不同类型的玩家以及他们喜欢什么，不喜欢什么。我们在本

章中学习了Jason VandenBerghe的五大游戏领域：新颖、挑战、刺激、和谐、恐吓，还有

第六点，剧情。接下来，了解了主要的人- 统计分类：男性和女性、男孩和女孩。在这部

分我们特别关注了如何设计女孩们喜欢的游戏。我们还研究了评定玩家等级的方法，以

及如何通过分级玩家来选择目标玩家。本章在最后讨论了二元性思维的危害，提出了一

个建议，即我们应该致力于包容性，而不是普遍性。在下一章中，我们将研究不同的游戏

平台。
