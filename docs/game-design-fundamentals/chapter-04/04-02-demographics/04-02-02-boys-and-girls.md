# 4.2.2 男孩和女孩

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 4 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：人口统计、性别包容、儿童玩家、女孩游戏、目标玩家

## 原书内容整理

电子游戏对于儿童来说和成人是不同的，电子游戏对于儿童就像看书和电视节目一样。

也不存在一种适合儿童的单一类型的游戏——童年时期他们的行动和认知能力是一直在变

化的。以下是受大众普遍认可的年龄划分：

- 幼儿园（年龄3～6岁）。

- 学前班（年龄5～8岁）。

- 小学低年级（年龄7～12岁）。

- 小学高年级（年龄13岁以上）。

- 青少年到20多岁。虽然处于这个阶段的人已经不能算是儿童了，但是他们的大脑

仍然在发育。

如果你想了解更多关于儿童发展的信息，请关注心理学家让·皮亚杰的工作。他的

认知发展理论对教育和许多其他相关领域都产生了巨大的影响。

大体上说，以上提到的每一个年龄阶段的群体都有每个阶段相应的兴趣和能力，主要

体现在他们的大脑和生理机能与成人有差异，好比性别，任何普遍性的规律都会有大量的

例外。关键要记住，千万不要把孩子看成是没有那么能干，没有那么聪明的迷你版成人。

在西方文化中，儿童更希望自己就是大人并渴望拥有和成人一样的特权，而且很反感

那些让自己看起来很幼稚的事情。一般来说，为某个年龄群体的孩子设计的游戏，其中的

角色年龄实际应该大于该群体玩家的年龄。而在其他文化领域中情况则是相反的，比如说

日本。

如果你正计划设计一款儿童游戏，需要考虑以下几个方面：

- 手和眼的协调：幼儿的行动能力在一开始发展得相当缓慢，行动能力的巅峰是在

青少年时期和20多岁的时候。在此之后，会随着年龄的增长而逐渐衰退。你必须

知道不同阶段手眼协调性的差异，并且在设计儿童游戏的时候把这些因素纳入考量

之中。

- 逻辑开发：儿童和成人一样都喜欢益智游戏，但对于幼儿来说，益智游戏应该反映

其逻辑推理能力的发展。幼儿的逻辑推理能力在6至7岁达到峰值，具体取决于孩

子的自身情况。针对该年龄段或者低于该年龄段儿童的益智游戏，可容纳一个提供

不同难度等级的能力范围（需要你进行测试验证）。相比于成人益智游戏，儿童益

智游戏涉及的元素会少很多，而且为了让孩子更好地体验游戏乐趣，逻辑推理链也

会短一些。

- 条理性思考：儿童一般在12～14岁之间开始条理性思考的发展。如果你的目标群

体年龄低于12岁，记住不要在游戏中加入复杂的系统。哪怕你认为是一个特别简

单的系统优化问题，对于这个年龄阶段刚开始进行条理性思考的孩子来说都是复

杂的。

- 短期目标和长期目标：在面向成人玩家的游戏中，玩家要达到一定目标通常需要使

用很多步骤。而儿童则更加关注及时的反馈和游戏设置。你不必非要在游戏中加入

一个可爱的角色，每次当孩子很好地完成某项任务时就会对他说“好棒！”，而是应

该优先考虑加入各种及时反馈的游戏体验，尽量减少长期目标。

- 视觉设计：相比于成人，小孩子缺乏过滤无关细节的经验，因此在儿童游戏中尽量

保持用户界面简单集中，把界面做深不要做太宽。

- 语言的复杂性：不要用讲道理的方式和孩子交谈，而是要用符合该年龄段的词汇和

语法。全是一些孩子不认识的词汇组成的长句会让孩子关闭对话框。由精心挑选出

来的词汇组成的短句也可以表达比较复杂的意思，比如读圣艾修伯里的《小王子》。

- 实验（尝试）：孩子有一种无止境的探索能力，他们的好奇心会促使他们全身心地投

人，并且不停地去尝试各种各样的事情。换言之，在游戏里他们会点击能看见的任

何东西。孩子的这种特性会引导游戏设计者在游戏里设置对探索型任务的奖励。

- 阅读：儿童，尤其是年龄更小的幼儿，阅读能力是有限的，甚至进入到青少年时期，

有些人还是不愿意花大量的时间阅读。对此，你可以设计一个语音叙述功能对重要

信息进行语音描述，并希望孩子们通过他们的想象力来补充剧情故事中的大量细

节，这细节需要你描述给成人玩家。

- 合适的内容：这个方面比较微妙，你必须权衡好父母希望孩子知道的内容和孩子自

已喜欢的内容，并花费大量的精力将这两方面的内容进行融合。既然是儿童游戏，

就需要在游戏中满足他们感兴趣的东西，而性和极端复杂的交易显然与他们的世界

无关。这就是儿童小说《哈利·波特》系列做得非常成功的地方，它的作者完美地

把握了孩子们的主要兴趣点。孩子们在阅读时，根据哈利被家人的误解以及他潜藏

在身体中而又未被开发出来的魔法能力，都能很容易地感受到哈利那种与众不同的

感觉。甚至对食物的关注也是儿童书籍中比较重要的部分，因为对于年龄比较小的

儿童来说，吃是他们的主要兴趣点，也是他们日常生活中占比很大的一部分。选择

儿童游戏的主题最好的办法就是去读一些在该年龄阶段流行的读物。

Carolyn Handler Miller是一个经验丰富的儿童游戏开发者。他总结出了“七大

死亡之吻”，其中的每一条内容，与其说会吸引孩子，倒不如说会将孩子从游戏中

赶走。所谓的“死亡之吻”，实际上是对孩子们喜好的一种误解，这种误解通常都

是来自家长们想要孩子喜欢什么的一种臆想。

- 死亡之吻#1：孩子喜欢任何可爱的东西。孩子是喜欢某些可爱的东西，但仅仅是

有时候，而不是任何时候都喜欢任何可爱的东西。想想华纳兄第的卡通动画：说

俏皮话的兔八哥，无休止地努力吃翠迪鸟的西尔维斯特猫，想尽各种办法置哔哔鸟

（Roadrunner）于死地的歪心狼（WileE.Coyote），杀气腾腾的山姆大叔（Yosemite

Sam）和野兔猎人艾玛（ElmerFudd）。孩子们喜欢的这些卡通人物中仍有一些是鬼

鬼票票地带有暴力倾向的，显然这些人物形象距可爱这个形容词相去甚远。

- 死亡之吻#2：总是给孩子大人认为是好的东西。孩子总是在被大人们教育，这个是

为你好那个是为你好。所以他们被强迫吃不喜欢的东西，强迫去学校，强迫去做家

务活，强迫去学钢琴，强迫去做很多有可能帮助他们塑造个人特性、增强体质和锻

炼大脑的事情。不得不承认，其中很多事情都是合理而且又是必需的，但是这些事

情完全不具备任何娱乐性。作为一个成年人，你是否喜欢在电视剧中插播大量的广

告宣传？你当然不喜欢，孩子也是一样的。当他们想要放松玩耍的时候，他们绝对

不想在这个过程中花一点时间去吃补品，哪怕这是对他们好。

- 死亡之吻#3：总想让他们快乐。这和第2条相反，有人可笑地认为由于孩子的内容

识别能力不及成年人，所以他们无法分辨老套琐碎的内容。事实并非如此，孩子们

无法说出来好的表演和糟糕的表演之间的差异，而且他们也没有足够的经验去识别

老套的情节，但是不能容忽任何无聊、老套、没有意思的东西是孩子的一种本能。

某种程度上，这是无需经过思维识别的过程。沃尔特·迪斯尼意识到了这点，还有

一些从事于儿童作品创作的作家和动画家同样意识到了孩子的这种特征，因此，即

使是在迪斯尼的儿童电影中，也会在情节中添加丰富的层次感。那些最受欢迎的儿

童读物也同样如此。因为，比起那些琐碎的内容，富含深意的内容会更长久地吸引

孩子们的注意力。

- 死亡之吻#4：总是谨慎行事。这是死亡之吻#1的变化形式。有些人尽其可能地避

免在游戏中出现暴力和有争议性的内容，并且试图删除一切可能让孩子受到惊吓，

哪怕是引起他们一点点心跳加速的东西。这必然丢失了游戏本身应有的娱乐性。我

们再一次回过头来，看看迪斯尼电影：小飞象和妈妈分散了，百雪公主恐怖地穿越

深林之行，《狮子王》中辛巴的父亲被谋杀。这些怎么说都不是令人愉快的内容，

但就是出现在电影中了，而且让人印象深刻。杰拉德·琼斯（GerardJones）在他的

文章《杀死怪物》中讨论了这个话题：为什么孩子需要幻想、超级英雄和虚假暴力

（Jones，2002），通过这些情况让孩子们学会处理危险情况是他们成长中很重要的一

部分。

- 死亡之吻#5：所有的孩子都是一样的。没有所谓的单一儿童游戏市场。孩子们的兴

趣和能力变化得太快，因此我们很难把他们整体划分到一个单一的分类中。如果你

计划设计一款针对6～10岁年龄段的儿童游戏，而出版商决定他们要发行的游戏是

针对8～12岁儿童的，那么没办法，你必须重新开发这个游戏。对于儿童来说，没

有通用设置的游戏。

- 死亡之吻#6：解释一切。相比成年人，儿童更容易在不断尝试中获得快乐，他们不

希望在游戏的一开始就出现一大段长的游戏说明告诉他们要如何玩。他们更喜欢

一头扎入游戏中边玩边摸索。尤其不要在游戏一开始说一大段莫名其妙的废话。站

在成年人的角度，理所当然地认为我们有责任向什么都不懂的孩子说明一切，但游

戏世界并不是真实的，在游戏中没有什么能让他们受到任何伤害。将说明性的元素

降到最低，尤其明显带有说教意味的东西。

- 死亡之吻#7：游戏角色太过健全。健全意味着无聊。我们在游戏中都无法容忍平淡

无奇的白面包式角色，那么为什么要让孩子去忍受呢？你无需引进连环杀手，但可

以创建看起比较真实的各有各弱点的角色。《芝麻街》（SesameStreet）因设计了各

种各样的角色而出名，而且给角色设计了很多在儿童身上常见的情绪：贪吃的、不

满的、有帮助的，等等。

提示：想更深入了解死亡之吻，请查阅Carolyn Handler Miller所著书籍《数字故事（第二

版）：创造者的互动娱乐指南》。
