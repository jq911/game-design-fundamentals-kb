# 9.7 设计练习——习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 9 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。
> 关键词：习题、自定义、创造型玩法、角色扮演、游戏修改

## 原书内容整理

1.如果允许玩家自行定义游戏设置，你希望哪些特征设置由他们自行设定：游戏人物的选

择、个性化定制，或是重新创建？玩家可以更改哪些属性？

2.当玩家选择个性化定制游戏人物时，你用何种方式让玩家明白相应的结果，根据此结果

玩家就能做出一个合理的选择？你会在何处放置该信息提醒？

3.如果你想要给出一个有创意的玩法，那么该游戏属于哪个领域？设备的限制又是在哪些

方面？

4.你是否计划推出一个限制创造性的玩法？如果是，你会约束哪些因素：经济方面、物理

方面或美学方面？游戏是否给玩家提供一个成长路径以逐渐解开对他们的约束？在美学方面，你如何实现美学评判机制，以及通过什么样的方式将该机制清楚地呈现给玩家？符合美学评判的构建物会不会帮助玩家赚取更多的钱、赢得奖章、获得更高的游戏点数，或者获得其他的奖励？

5.你是否计划推出一个自由创造型玩法？如果是，它是普通玩法的一部分，还是将其设计

成一个单独的沙盒模式？如果你提供了一个自由创造型玩法，玩家的构建物是否会对游戏可玩性产生影响？

6.你的游戏是否包含角色扮演或故事叙述的玩法？这种玩法是什么样子的？如何将这些特

征无缝地融入到整个游戏当中？

7.游戏中是否允许使用游戏修改？你会允许玩家修改哪些东西？玩家是否能够自行创建关

卡、机器人或叙述题材？你想用什么工具来实现这些内容？

8.你如何创建玩家之间的社区，并允许他们与社区中的其他人共享构建物？
