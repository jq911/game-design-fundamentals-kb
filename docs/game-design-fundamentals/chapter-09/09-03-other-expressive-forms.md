# 9.3 其他的表达形式

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 9 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。
> 关键词：表达形式、角色扮演、故事叙述、化身、玩家创作

## 原书内容整理

本节涵盖了不涉及使事情具有实质性（如建立虚拟城市或绘制图片）的创意游戏形式。作为游戏玩法常见的两种主要表现形式是：角色扮演和故事叙述，分别介绍如下。

### 9.3.1 角色扮演

角色扮演这个术语在游戏中相当重要，因为它可能意味着从真实的即兴演出到简单地使用《龙与地下城》风格的规则玩电子游戏。为了让读者更好地理解本章，角色扮演意味着控制化身角色，使其展示真实人物的一些行为或个性特征。为了给玩家提供作为角色的机会，你必须首先设计玩家所玩的化身，并决定玩家可以修改它的程度。我们已经在9.1节做了简要介绍，同时在第10章中有更多的内容。在这个过程中，你还必须决定通过什么手段，让玩家使化身看起来更像一个人，而不只是提线木偶。玩家可以通过声音、动作和面部表情来描绘角色。在戏剧表演中，这些细节通常已由导演预先安排好，但在电子游戏中大多是即兴的，当然这一切都必须通过游戏的用户界面呈现在玩家眼前。以下是你可能会考虑实现的一些功能：

- 情绪指示器。目前，大多数游戏不给玩家以任何方式改变化身的面部表情。情绪指

示器是一些可供玩家选择的图标，其允许玩家以简单粗暴的方式（切换图标）来指示化身的状态。游戏引擎可以检测情绪并使NPC做出适当反应；在多人玩家游戏中，其他玩家也可以看到它。

- 表情。大型多人在线角色扮演游戏（MMORPG）通常提供表情、特殊的动画等，

玩家可以通过触发来指示情绪状态的机制，但这些当然没有真正的身体语言微妙。《魔兽世界》中提供的舞蹈就是一个例子。表情通常用于娱乐其他玩家，而不是影响游戏引擎。

- 对话选择。让玩家制定角色的最常见方法是在与NPC的对话中向他们提供几种不

同的方式来表达同样的东西。你可以给玩家积极、礼貌或幽默的方式回答另一个角色。玩家的选择影响角色的态度，并可能打开或关闭不同的对话线。它也可以通过改变NPC对玩家的态度来影响游戏引擎。这些只是一些设计建议，让玩家表达自己在游戏中无法通过身体动作来传达的想法。角色扮演允许玩家感觉自己在扮演他人，这是一种强大的娱乐功能和个性的自我表达。

### 9.3.2 故事叙述

有的玩家喜欢用游戏里提供的东西创造自己的故事，然后发布到网上让别人阅读。狮头公司出品的《电影大亨》是目前这类游戏中最有发展前途的项目。这类游戏的目的是让人们自己制作电影，然后在网上与别人分享。《电影大亨》允许玩家导出电影并使用像Adobe Premiere这样的外部视频编辑器来编辑影片。《电影大亨》提供的表现力比其他任何故事讲述型游戏都多，但是它需要玩家付出很大努力。如果你想设计一个有类似特征的游戏，你必须和程序员合作设计一个这样的系统：允许玩家在游戏世界里安装摄像机，记录游戏引擎生成的图片和声音，然后编辑它们。独立设计师Jason Rohrer在他的游戏《小憩即永眠》中使用了另一种方法。这个游戏是为讲故事的人和故事主角这两个玩家设计的。讲故事的人为故事主角创造实时的故事体验，并对主角的行动做出反应。它与桌面角色扮演在这方面有一些共同点，但它避免了所有的数字问题和强调任务模式以及魔法物品。游戏很小，图形也是复古的，但《小憩即永眠》从一出版便收获了诸多好评，是非常值得你花时间调查的游戏。然而，你大可不必那么麻烦。事实证明，《模拟人生》使用一个更简单的故事讲述机制，同样取得了巨大的成功。在这个游戏中，玩家可以创造人物，建房子让他们住，然后通过发出命令来发起事件。《模拟人生》还允许玩家从游戏里抓取截图，贴上标签，组织到故事板中，上传到网页上让别人读。这样讲故事比《电影大亨》使用软件要简单得多，而且玩家也不用知道如何编辑视频。另一个更简单的办法是把玩家的活动用文本记录下来。她可以随意编辑这个记录，把原始的游戏动作和对话变成叙事形式。
