# 9.5 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 9 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。
> 关键词：总结、自我表达、创造型玩法、游戏修改

## 原书内容整理

玩家喜欢表达自己和建造东西。本章我们通过化身选择、定制、建造展示了自我表达的一些选择。我们研究了自由创造型玩法和受限创造型玩法，讨论了一些你可以为玩家的创造力设置的不同限制，以增强挑战性。我们还讲了故事讲述型玩法的一些选择，结尾简单讨论了允许玩家修改游戏方面的内容。有了这些工具，你应该能为游戏添加一些创造性玩法。
