# 9.6 设计练习——训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 9 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。
> 关键词：训练题、属性、创造型玩法、美学规则

## 原书内容整理

1.找一个你熟悉的游戏（或者指导老师分配给你的游戏），并且该游戏允许玩家个性化定制

他们的游戏角色，辨别并记录玩家喜欢在游戏角色上修改的功能属性和装饰属性。对于功能属性，指出这些属性会对游戏可玩性产生什么样的影响？

2.给一个游戏想一个点子，让该游戏允许玩家构建一些在以前的盈利性游戏中你从未见过

的东西（没有城市、建筑和汽车）。假设你能够通过控制资金的手段来约束玩家的构建能力，但允许他们利用额外时间获得新的构建工具和特征。设计一套基本的构建部件，并指定每个部件的价格。包括部件的等级提升——用价格更高的部件替代之前比较便宜的同类部件。写一个小短文，说明玩家会去创造哪些领域，并提供你的部件清单，让玩家有足够的能力去获得它们（从最便宜的开始）。并指出玩家一般如何通过他们所建造出来的物品来赚钱。你的指导老师会告诉你该练习的创作范围。

3.选择一个游戏领域，玩家在此领域中所构建东西的美学标准必须符合现实世界认可的一

系列美学规则，比如，建筑、服装设计、音乐、室内装饰、景观美化，或指导老师指定的领域。研究你所选择领域的美学规则（随着时代的更迭，每个时期的美学规则都会发生变化，因此你应该研究符合所选时代的所有美学规则的资料）。研究要仔细，不要混淆各美学规则的可用性。写一篇小短文阐述你的领域，其中包括玩家构建物品的可选范围，以及相应的美学规则文本。需要提供所选资源的参考文献。
