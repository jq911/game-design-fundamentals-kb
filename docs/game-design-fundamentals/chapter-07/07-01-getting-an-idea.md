# 7.1 获得一个创意

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：创意来源、梦想、其他媒体、其他游戏、头脑风暴、交流愿景

## 原书内容整理

只要认真寻找，你几乎可以在任何地方获得游戏创意。创造是一个主动的，而不是被动的过程。放眼四方，某些最普通的东西也可能隐藏着一个游戏创意。例如《生化奇兵》，就像是一个针对安兰德所提出的哲学问题——“在一个对生物实验完全不加管束的乌托邦世界里，最有可能发生什么事情？”——而特别设计出来的讽刺性作品。相比之下，《愤怒的小鸟》就单纯得多了：它只是一个简单添加了物理引擎的拉弹弓的射击游戏而已。在此之前已经有过许多种弹弓射击类游戏，但是都没有设想得这般巧妙。仅有创意是不够的。人们通常会错误地认为一个好的游戏创意就可以给你带来财富。实际上，这种情况很少发生。即使你认为你拥有这个世纪以来最好的游戏创意，你也应该去期待更多。记录下每个创意然后继续寻找。如果某一个看起来非常有前景，那么你可以开始拓展并重新定义它，但是也不要让它阻止你思考其他游戏的脚步。当提到游戏创意的时候，总是越多越好。
