# 7.2 从创意到游戏概念

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏概念、高级概念文档、玩家角色、游戏类型、目标人群、游戏进度

## 原书内容整理

在第2章中，我们把游戏概念描述为“关于你打算怎样通过游戏可玩性娱乐某人的一般创意”。从整体上把握，那个描述已经足够了，但是为了详细地讨论游戏概念，我们需要一个更完整的解释。游戏概念是游戏的详细描述，可以把它当作潜在的商业产品来谈论，这里的商业产品指的是公众可以购买的软件。它最少应该包括以下几个方面。

- 高级概念表述是有关游戏内容的两三句话的描述。如一款关于街头足球游戏的高级

概念表述是：“勇敢者的游戏。没有球拍，没有头盔，没有裁判，没有场地，只有你和其他家伙，以及一个球和宽广的混凝土场地。”

- 如果游戏描述具体到了某个角色，那么还应包括玩家在游戏中的角色。如果玩家有

一个化身，那么应简短地描述化身。

- 推荐的基本游戏模式，包括视角、交互模式和玩家在那种模式下所经历的一般的挑

战类型。

- 游戏的种类，或者对该游戏不能归入现存游戏分类的解释。

- 对游戏目标人群的讨论。

- 游戏可以运行的机器的名字，以及游戏要求的所有特殊设备的细节（例如，摄像头

或跳舞毯）。第5章讨论了游戏机的多样性。

- 一个简短的声明来解释你希望以何种方式通过自己的游戏来挣钱。如果你打算进行

商业销售，可参阅第6章，其中介绍了世界上各个地区的游戏市场，以及游戏行业中的商业模式。

- 游戏所依据的被认证的角色或者其他有知识产权的角色，如运动员或电影英雄。

- 游戏支持的竞争模式：单人、双人或者多人竞争或者合作。

- 对游戏怎样开始到结束的概要总结，包括一些对关卡和任务的创意。如果游戏有故

事情节，那么还要有游戏情节的大纲。

- 游戏世界的简短描述。

你应该把所有这些条目放到一个高级概念文档中。本章将讨论怎样思考这些问题，除了一些可以自我说明或者在前面章节讨论过的条目。在配套网站上你可以找到一个高级概念文档样本。在商业环境中，发行商还希望看到几条附加的细节：游戏潜在的竞争力、游戏的独特卖点（Unique Selling Points，USP），即让你的游戏在市场中站得住脚的东西，可能的市场策略和相关的商业机会。正如你看到的，游戏概念比创意复杂很多。它是一个你已经思考过并开始着手开发的创意。一个游戏概念包括足够多的细节来讨论玩游戏的感觉怎么样以及需要如何进一步工作来创造这个游戏。提示：使用高级概念文档的方法来介绍游戏的一个实用技巧就是，脑补一个“初识游戏的前5分钟”的场景，然后对此进行描绘，这样就能给人清晰的画面感，知道在你的游戏中会面对何种情况。
