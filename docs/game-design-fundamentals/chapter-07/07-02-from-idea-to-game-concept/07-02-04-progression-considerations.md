# 7.2.4 游戏进度考虑

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏概念、高级概念文档、玩家角色、游戏类型、目标人群、游戏进度

## 原书内容整理

如果你的游戏很长，那么就需要使玩家在游戏过程中感觉到是在前进，而不是始终在原地踏步。在游戏的设计阶段，你必须决定什么可以提供这种前进的感觉：关卡？故事？还是两者都有。你的游戏是不是太长了所以应该分为不同的关卡？关卡之间是不相关的，玩家可以在任何时间玩任何一关，或者它们是按照一定的顺序或者分支进行配置的，玩家只有完成了一关才能进行下一关？什么情况才能确定玩家已经完成了一关？你选择的游戏类型会帮助你确定这些答案。另一个问题是你是否需要一个故事。故事赋予游戏上下文环境和目标。有些游戏，像运动游戏和益智游戏，通常不包含故事情节，因为它们的上下文环境是自解释的。在其他的类型中，例如角色扮演游戏和冒险游戏，故事则是游戏娱乐性的一大部分。具体的游戏通常都有一个故事背景，而抽象的游戏一般都没有，当然《吃豆人小姐》在一些小地方是一个例外。很少有涉及关于抽象角色的故事。如果你确实决定了要在你的游戏中包含一个故事，那么在概念形成阶段你不必确切地知道你希望包括什么样的叙事内容。你需要知道是否希望包含故事，这样也就知道了游戏的大体方向。你应该用一两句话来概括它，例如：“Moses Oyeleye，一个普通的美国大学生，正准备继承他父亲在尼日利亚的农场，结果却意外卷入了当地匪帮、警察，以及西方石油公司的三方斗争当中。为了拯救自己的家人和获得继承权，他不得不走上斗争的道路。”更正故事情节中的错误远比更正游戏可玩性中的错误要容易得多，并且游戏者也会更快地原谅故事情节中的错误。因此首先要保证你自己能理解你的游戏，然后在其中构建你的故事。

#### 设计点拨：故事在以后构建

在概念阶段不要花费很多时间设计故事情节。这是一个严重的错误，习惯于书籍和电影那样表现性媒体的人经常犯这样的错误。这个时候，你应该把大部分精力放在游戏可玩性方面。
