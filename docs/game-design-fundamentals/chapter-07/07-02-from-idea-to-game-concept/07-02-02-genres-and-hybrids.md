# 7.2.2 游戏类型和混合体

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏概念、高级概念文档、玩家角色、游戏类型、目标人群、游戏进度

## 原书内容整理

如果你是学生或独立开发者，我们建议你在设计游戏时所做的第一件事便是定义玩家的角色，并考虑该角色可以使用的操作。这给予了你最大的灵活性，去创建任何你喜欢的游戏。然而，如果你正在为一个大型的常规出版商工作，他们可能会希望你做一个适合现有类型的游戏。发行商用在游戏开发上的钱越多，他们就越保守。在游戏设计师的菜鸟阶段，可以考虑先进行射击游戏或赛车游戏这样知名类型的创作，这会为你提供早期设计过程的捷径。因为这种游戏类型是根据它们的挑战来定义的，所以游戏中自然有一套相当标准的行为，玩家也期望在同类游戏中可以互通。在本书第3章中有详细介绍。而有一些游戏会跨越类型，将不同的功能组合在一起以至于很难进行分类。到目前为止，最成功的混合体是“动作+冒险”，如最新的《塞尔达传说》（Legend of Zelda）（早期的2D版塞尔达传说几乎完全是动作游戏）。“动作+冒险”游戏中占主要作用的仍是动作，但它们通常也会包括一个故事和解谜，这样便有了冒险游戏的元素。在一种类型中提供主要游戏模式，而在另一种类型中提供一个或多个迷你游戏模式的游戏越来越受欢迎。例如，《益智之迷》（Puzzle Quest）（见图7-2）便是一个成功的混合体：本身是一个简单的角色扮演游戏，但使用了“三消”这个用于许多休闲游戏的模式来实施战斗。

交叉类型会让设计和开发团队增加更多工作，同时风险也会增大。虽然混合类型可能会吸引到两类玩家群体，但也有可能最终两类人都吸引不了。许多玩家（和游戏评论者）喜欢特定的类型，并且不想面对他们通常避免的某种挑战。如果你打算做一些不寻常的改变，一定要早点与代表你目标受众的人一起检验你的想法。然而，你不应该让标准类型限制住你的创造力——特别是在概念阶段。如果你有一个全新的、从未见过的类型游戏想法，要记得设计它，如你所想；不要试图把它钉入它不属于的类型。游戏需要本身是真实的，所以真正的混合游戏可能需要混合通常不会一起呈现的挑战。但是没有好的理由，不要混合不同类型的特征；一个游戏应该跨越流派，此时它才真正需要作为游戏的一部分。一个飞行模拟器与逻辑拼图插入在游戏的中间，只是为了使游戏不同于其他飞行模拟器，而这只会惹恼飞行迷。
