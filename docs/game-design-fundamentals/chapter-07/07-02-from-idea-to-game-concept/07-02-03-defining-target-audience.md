# 7.2.3 定义你的目标人群

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏概念、高级概念文档、玩家角色、游戏类型、目标人群、游戏进度

## 原书内容整理

许多游戏设计者都有一个错误的观念，那就是所有的玩家都会喜欢设计者本人所喜欢的东西，所以设计者只要检测他自己的体验就可以知道怎样让一个游戏具有娱乐性了。这是一种危险的骄傲情绪。制作计算机游戏的目的是娱乐它的拥护者。你必须考虑这些人是谁，他们喜欢什么。第4章和第6章中解答了一些你可能会遇到的问题。除非你受人委托，否则你是在为一类人设计游戏，而不是一个人。在设计游戏的早期阶段，你必须大范围地思考游戏的目标人群，他们就是你认为会喜欢这个游戏的人群。发行商首先会问你的一个问题是“谁会买这个游戏？”仔细地思考这个问题的答案。你的玩家可能会有什么共同点？什么东西把他们和其他游戏者区分开？他们喜欢什么样的挑战？更重要的是，他们不喜欢什么类型的挑战？什么吸引他们？什么使他们感到厌倦？什么使他们沮丧？什么使他们兴奋？什么让他们害怕？什么会让他们不愉快？回答这些问题，而且在你设计游戏时要时刻想着这些答案。如果你对自己的游戏玩家还不是很了解，就多找找这个圈子内的朋友聊聊，并且仔细观察他们所玩的那些与你设计的游戏有相似之处的其他游戏。

#### 供你参考：以玩家为中心的哲学和目标人群

正如我们在第2章中解释的，游戏设计中以玩家为中心的哲学要求你思考你的设计决定是怎样影响代表性玩家的游戏体验的。这种方法保证了你的决定首先是为玩家服务的，特别是在开发的后期阶段，在你做决定经常会受到像花费和便利这样的诱惑时，更是如此。如果没有对目标人群的研究报告，那么一个游戏概念是不完整的。定义目标人群和以玩家为中心的设计不同。只有在定义了目标人群之后你才能使用以玩家为中心的方法。开始的时候你必须问自己：“我要设法娱乐谁？”一旦有了答案，你就可以用它把以玩家为中心的方法应用到其他设计问题中，你可以问自己：“这种特征可以娱乐我的目标人群中的代表性玩家吗？”
