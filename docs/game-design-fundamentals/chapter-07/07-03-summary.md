# 7.3 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 7 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：总结、游戏概念、高级概念文档、玩家角色、目标人群

## 原书内容整理

在本章中，你学到了什么是游戏概念以及为了创建一个高级概念文档你需要做出哪些决定。现在你应该理解了定义玩家角色的重要性。你也了解了各种游戏类别之间的区别以及怎样选择目标人群——特别要注意他们热衷游戏的程度。你应该也知道了你选择的机器是如何影响人们玩游戏的。创造一个游戏概念就像是设计一栋大楼的主框架：它给你一个大体的轮廓但是没有细节。本书其他章节会专注于如何创造这些细节。
