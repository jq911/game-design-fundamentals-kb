# 第 12 章 创造用户体验

## 本章定位

本章整理原书第 12 章关于用户体验与用户界面设计的内容，重点关注交互模型、视角、视觉/音频反馈、输入设备、导航、辅助功能与定制。

## 复习线索

- 用户界面如何把玩家输入转换为游戏世界中的动作，并把反馈传回给玩家。
- 以玩家为中心的界面设计原则，以及如何管理复杂度。
- 交互模型、视角、视觉元素、音频元素与输入设备之间的关系。
- 导航、辅助功能和定制选项如何影响玩家体验。
