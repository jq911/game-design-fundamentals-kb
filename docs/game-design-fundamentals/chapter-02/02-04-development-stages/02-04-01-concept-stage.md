# 2.4.1 概念设计阶段

> 关键词：概念设计、细化阶段、调整阶段、原型、迭代

#### 1. 获得游戏概念

所有的游戏设计都必须从游戏概念开始，一般是一个通过游戏可玩性娱乐某些人的想法，或者更深一点，就是你为什么相信它会成为一个吸引人的体验。很多不同的考虑都会影响你对游戏的概念计划。创建游戏概念的工作还包含决定你的游戏属于哪一种类别（如果42有）。如果你要设计的游戏在市场上已经有了其他类似的游戏，你可以试玩一下，看看它们是如何运作的，同时思考要如何改进它们。第7章中会详细地讨论如何定义和修改游戏概念。

#### 2. 定义目标人群

环境中，发行商有时会定义他们的观众（目标市场），然后才会考虑卖给他们的游戏概念。在任何情况下，你做出的选择都对你的游戏有很重要的影响，因为在以玩家为中心的设计中，你要根据假想的玩家代表来测试你的设计决定，这样才能保证这个决定可以帮助你娱乐目标人群。

#### 3. 确定玩家角色

在一个抽象的电子游戏中，玩家不会沉浸在虚幻的游戏世界中，因此也就谈不上玩家角色了。他只是一个由于自己的原因玩游戏的玩家。但是在表现型游戏中，玩家确实做了很多假想。他假设自己相信这个游戏世界、化身和游戏把他放置的环境。在这样的游戏中，玩家扮演了一定的角色。而作为设计者，你可以决定玩家到底扮演什么样的角色。它可以是运动员、将军、舞蹈演员、探险家、商业大亨或者人们幻想的任何其他角色。有时候一个游戏中的角色是多面的：在运动游戏中，玩家经常从场上的运动员变为场下制定策略的教练，或者变为雇佣或者交易球员的经理。你必须能清楚地解释玩家的角色，因为游戏可

#### 4. 实现梦想

抽象电子游戏有任意的规则，所有玩家对游戏允许或者不允许他们做什么很少会预先有一个了解。然而，在某种程度上表现型电子游戏发生在熟悉的世界里，因而玩家会带着某种期待和希望来玩游戏。表现型游戏是关于实现梦想的——成就的梦想、力量的梦想、创造的梦想或者简单地做某些事或者有某种体验的梦想。一旦你的脑海中有了游戏概念、角色和目标人群，那么就是开始思考你怎样实现玩家的梦想的时候了。你将提供的体验的本质是什么？玩家想要面对的挑战的类型是什么，她希望采取什么类型的动作？实现梦想的决定意味着这是通往定义游戏可玩性本身的道路上的第一步。设计点拨：概念元素是永久的一旦开始进入游戏的详细设计阶段，你就不能修改游戏中的概念元素——游戏概念、目标人群、玩家角色和游戏要实现的梦想。
