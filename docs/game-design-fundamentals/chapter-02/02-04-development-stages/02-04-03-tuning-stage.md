# 2.4.3 调整阶段

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：概念设计、细化阶段、调整阶段、原型、迭代

## 原书内容整理

当游戏从概念阶段走向细化设计阶段时，设计师确定了游戏的概念——游戏的基础。而在细化设计阶段，设计师需要充实概念并添加新功能。然而，在某些时候，整个设计都已经提前规定好了交付时间，也就是说，没有更多的功能可以添加到游戏当中了——因此进入了调整阶段。这个转换阶段有时称为“功能锁定”。没有什么好的方法来确切地定义该阶段的内容。它通常由日程表决定，如果它在所有剩余时间都将完成和修复游戏bug作为主要目的，那这无疑就表明了设计师不能再添加任何更多的设计，否则项目就要延期！因计已经完整且和谐的时候便进行锁定，这样有更多的时间进行其他的设计工作。一且你锁定了设计，仍然有其他的工作要做。在调整阶段，只要不引入任何新功能，都可以对游戏的关卡和核心机制进行微调。在这个时期，你的大部分工作是微调游戏的平衡性，这正是我们在第15章中将要详细讨论的主题。这个阶段比任何其他阶段都更重要，是“好的游戏”和“伟大的游戏”之间真正的差别所在。调整和打磨你的游戏，直到它至臻至美。这里要记住的是，打磨是一个做减法的过程，而不是加法。因此你不会加入新的铃声和口哨，相反，你要消除多余的瑕疵，使游戏光彩照人。
