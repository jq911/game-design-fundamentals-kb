# 2.2 电子游戏的关键组成

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：核心机制、用户界面、表示层、交互模型、视角

## 原书内容整理

在第1章中，我们讨论了什么是游戏，什么是游戏的可玩性。但是游戏的可玩性来自何处，玩家如何与它进行交互，这些并没有探讨。为了创建可玩的游戏并将它们提供给玩家，有两个关键组件。这两个组件不是技术上的，而是概念上的：核心机制和用户界面。有些游戏也会用到第三个重要组件：故事叙述引擎，我们会在第7章中讨论。在这一节中，我们将介绍核心机制和用户界面，并说明它们是如何共同工作来产生娱乐性的。在本书的后面，每个组件均有完整的一章来讲解，所以我们这里的讨论限定在对功能的定义上，而不是解释如何设计它们。
