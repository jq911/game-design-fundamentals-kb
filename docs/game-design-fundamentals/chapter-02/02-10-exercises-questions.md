# 2.10 设计练习——习题

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：思考题、以玩家为中心、设计者素质、团队角色

## 原书内容整理

#### 1. 简述以玩家为中心的游戏设计方式的优点和缺点。请分析在什么情况下以玩家为中心的游戏设计方式会与游戏中的其他需求发生冲突，或与游戏设计者想法冲突？

#### 2. 你认为我们列出的作为一名优秀游戏设计者应该具备的素质是否完整？还需要添加哪些素质？有哪些素质你认为是不需要的？

#### 3. 我们所列出的设计团队成员没有包含主程序员，是否应该这么做？请提出你的正面和反面建议。
