# 2.4 游戏开发过程中的各个阶段

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：概念设计、细化阶段、调整阶段、原型、迭代

## 原书内容整理

既然你已经学习了以玩家为中心的游戏设计方法、电子游戏的关键组成部分和游戏结构，那么你就可以开始考虑怎样去设计一个游戏了。遗憾的是，这个世界上电子游戏的种类太多了，不能定义一个按部就班的过程生成单一的设计文档来让开发人员转变为游戏内容和代码。更重要的是，除非游戏非常小，否则不可能创建一个完整的文档然后再编写代码。这就是20世纪80年代游戏产业创建游戏的方法，但是经验告诉我们大型游戏的设计和构建是一个反复的过程，在整个开发过程中需要不停地测试和调整，不时地修改设计。然而，设计过程中不是所有的部分都需要返工。某些部分（例如概念、目标人群和游戏类别）的选择就应该在开始一次确定好，以后就不能再改了。因此整个过程分为3个主要部分：

- 概念设计阶段（conceptstage）：最先执行，结果不会改变。

- 详细设计阶段（elaborationstage）：在这个阶段加入大部分设计细节，并通过原型化方法和游戏测试来重新定义你的设计决定。

- 调整阶段（tuningstage）：这时候不能再加人新的特征，只能为优化游戏做些小的调整。我们选择使用术语“详细设计阶段”而不是开发阶段，因为后者可能会与游戏开发混淆。图2-6显示了游戏过程的三个阶段。

每一个阶段都包含很多设计任务。在接下来的部分中，我们将讲述每个阶段以及需要完成的任务。Chris Bateman 和 Richard Boon在他们的书《21世纪的游戏设计》（21st Century Game Design，Bateman 和 Boon，2006）的第1章中讨论了各种设计过程的优点，我们推荐你阅读这本书来完成对这个课题的进一步讨论。我们尽最大努力使用其他专业开发者一般会认可的术语，但是我们警告你并不是所有的公司都按照我们定义的术语来使用。如果你感到困惑，请参考术语表中对各个术语的定义。
