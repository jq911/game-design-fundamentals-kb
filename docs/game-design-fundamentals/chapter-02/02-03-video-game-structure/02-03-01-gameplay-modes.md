# 2.3.1 游戏可玩性模式

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏可玩性模式、shell 菜单、shell 屏幕、结构转换

## 原书内容整理

如果希望一个游戏前后一致，那么在任何给定的时间里，玩家可用的挑战和动作在概念上都应该是彼此相连的。例如，在白刃化的格斗中，玩家应该可以到处移动，挥舞他的武器，服用回血药剂（虽然可能会承担一定的风险），还可能会逃跑或者投降。他不能拿出地图，或者坐下来整理他的背包，但在游戏中的其他时间他可以使用这样的动作。简而言之，除非一个游戏非常简单，否则在同一时间并不是它提供的所有挑战和动作对玩家都是可用的。用户界面也应该设计得有利于正在发生的所有动作。驾驶一辆赛车时显示的图像有必要与在商店中维护这辆车的图像不同。视角和互动模型也不同。驾驶的时候，交通工具就是玩家在赛道上的化身，玩家通常从驾驶员的位置上观察世界；当维护汽车的时候，玩家可以控制赛车的所有部分，但是游戏世界的其他部分（赛道）就看不到了。相关项的组合——在游戏给定点的可用的游戏可玩性和支持的用户界面——共同描述出了游戏可玩性模式（gameplay mode）。图2-3所示的是一个说明，在一个给定的游戏可玩性模式中，游戏的各种特征组合在一起给玩家某种有别于游戏的其他部分的感觉，也就是有别于其他游戏可玩性模式的感觉。由于在一个给定的游戏可玩性模式中，游戏提供的只是它的所有挑战和动作的子集，所以玩家可以专注于有限数量的目标。

游戏可玩性模式是设计电子游戏过程的中心。因此，我们提供了下面的正式定义：

> 游戏可玩性模式由游戏的所有时间里可用的全部游戏可玩性的子集，以及向玩家表示这个子集的用户界面组成。在某个时间游戏可能只有一种游戏可玩性模式。当玩家可用的游戏可玩性或者用户界面做出重大改变时，游戏就离开了这种模式，进入另一种模式。我们把用户界面的改变包含在模式改变中，因为这样的改变使玩家的注意力中心改变了方向，并使他们开始思考不同的挑战。如果输入设备上的按键与游戏中的动作之间的映射急剧地改变了，那么玩家也可能把它作为一种新的模式来考虑。许多早期的街机游戏只有一种游戏可玩性模式。例如，在《太空射击》这款游戏中，玩家控制的太空飞船周围有许多小行星，玩家要通过射击来击毁小行星，以避免被它们撞到。相机模型和交互模型从不改变，控件的功能也不变。另一方面，在《吃豆人》游戏中玩家会被危险的鬼魂追逐，直到玩家在球场上吃下一个大点。在吃下大点后的一段时间内，鬼魂会变得脆弱并逃离玩家。《吃豆人》的这种设定表示游戏玩法已经有了重大的变化（并且是在游戏策略中的关键部分）。即使用户界面不改变，也可以被认为是新的游戏可玩性模式。一种模式与另一种模式的差别定义并不严格，但是当玩家感觉到游戏的某些内容发生了显著的变化时，它可能已经进入了一种新的模式。迷你游戏同样也是新的游戏模式。

#### 美式足球中的可玩性模式

关于美式足球的电子游戏有很多快速和复杂的模式转换，特别对进攻方，也就是持球一方来说。控制器上的按键和它们产生的动作之间的映射几乎每秒都在改变。下面就是《麦登橄榄球》中选择和执行传球动作所需的操作序列：

#### 1. 从目录中选择下一次进攻所使用的队形。

#### 2. 从另一个目录中选择调用的操作。

#### 3. 选择控制四分卫，发出底线混战的信号。在这段时间里，只有那个不是四分卫的人可以在玩家的控制下移动，把球快速传给四分卫。

#### 4. 从底线混战中跑出来并迅速找到一个无人防守的接球者。选择这个人，按下合适的按键把球传给他。

#### 5. 控制选择的接球者，向球飞向的方向奔跑。按下适当的按键来接球。

#### 6. 向得分线奔跑。这时候，球可能不会被再次扔出。这个过程要求在45秒左右的时间里执行6种不同的可玩性模式。图2-4和图2-5所示的是《帝国时代：全面战争》中两种不同的可玩性模式。第一种是回合制模式，显示了从全景视角进行观察。玩家使用这个视角来建造城市、组织军队，以及进行其他的策略性活动。第二种模式实时显示了游戏中的海战模式，它通过一艘船的视角来观察另一艘船，在这种视角下，你只能与视野范围内的敌方战舰进行火拼。这种海战模式无疑是一种战术模式。

不是所有的可玩性模式都提供玩家必须立即遇到的挑战。即使游戏被暂停，运动游戏中的策略目录也是一个可玩性模式，因为玩家必须选择最好的策略来帮助自己取得胜利。角色扮演游戏中的人物创建屏幕或冒险游戏中的物品管理屏幕都可以认为是游戏可玩性模式。在那里一个玩家的动作会影响她回到常规游戏中将遇到的挑战。如果一个玩家采取影响核心机制的动作（即使这个影响可以推迟），那么游戏就处于一个可玩性模式中。如果不影响，游戏处于shell菜单或者shell屏幕中。
