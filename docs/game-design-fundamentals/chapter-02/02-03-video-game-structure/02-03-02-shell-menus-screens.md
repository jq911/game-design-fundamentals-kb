# 2.3.2 shell菜单和屏幕

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：游戏可玩性模式、shell 菜单、shell 屏幕、结构转换

## 原书内容整理

不论何时，只要玩家采取影响游戏世界的动作时，实际上就是在玩游戏，那么游戏就处于一个可玩性模式中。然而，大部分游戏都有几种模式，在这些模式中，玩家不能影响游戏世界，但是可以做出其他改变。这些模式放在一起称为shell菜单，因为经常在游戏开始或者游戏结束之后用到这些菜单（它们是游戏周围的shell，处于魔法圈之外）。shell菜单中各种可用的动作的例子包括载人和保存游戏，设置音量大小和屏幕分辨率，为了玩家的便利重新设置输入设备等。游戏中的暂停菜单也是一个shell菜单，除非这个暂停允许玩家采取影响游戏世界的动作（例如运动游戏中做出策略调整），这种情况是一种可玩性模式。象截屏和标题屏幕这样非交互式的屏幕序列称为shell屏幕。电子游戏通常不是处于游戏可玩性模式就是处于shell菜单或者屏幕中。
