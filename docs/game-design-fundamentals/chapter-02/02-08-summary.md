# 2.8 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：本章总结

## 原书内容整理

本章提出了游戏设计不是一种神秘的艺术而是一门手艺的观点，它和其他手艺一样，通过应用都可以学会。

电子游戏不是通过神秘的偶然的过程创造的。相反，它们是设计师通过规则和表现层，供给玩家消遣体验。一个游戏在概念设计阶段创建一个概念并锁定目标人群，在细化设计阶段充实各个细节，把抽象的想法变成具体的计划，并在调整阶段使它变得完美。

所有的电子游戏都有一个由游戏可玩性模式和 shell 菜单组成的结构，你必须记录下这个结构，这样你的团队成员才能知道他们正在组建的是什么以及它们如何结合到一起。在这个过程中，你需要使用很多的技能来为团队编写各种各样的文档。在所有时间里，你都应该为玩家寻找一个集成的、一致的体验来完成你最重要的职责：娱乐玩家。
