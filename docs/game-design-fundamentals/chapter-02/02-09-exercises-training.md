# 2.9 设计练习——训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：训练题、流程板、可玩性模式、关卡进程

## 原书内容整理

在以下这些练习中，你用现有的游戏进行记录。你的指导老师会要求你用他非常熟悉的一些游戏来做这项练习，并且他会设置预期的工作范围——他想看到的资料的数量。请使用一个文档模板（该模板来自合作网站或者由你的指导老师提供）。

#### 1. 在文档中写出你喜欢的一款小游戏的主要游戏可玩性模式。文档中要包括：该游戏在显示器上的草图、视角以及用户界面；包括该模式用到的所有按键和菜单项在内的清单；一个除初始模式外其他模式的清单，这些模式可以由初始模式切换。请描述组成该模式的挑战和动作。

#### 2. 请选择一个经典的著名的街机游戏（该游戏只需含少量的游戏可玩性模式和shell 菜单）并为该游戏创建一个流程板。（由于你无法提交整个页面，请你创建一个微型版本，每个工作表中包含两到三个游戏可玩性模式即可。）

#### 3. 在文档中写出一个你曾经通关过的著名游戏的关卡进程，比如《星际争霸》或者《辐射3》（如果是像《半条命》这类没有明显关卡的游戏，请写出游戏的主要场景或片段）。请描述每个关卡中的游戏世界以及当前呈现出来的挑战类型。如果关卡是融合到剧情当中的，请说明每个关卡是怎样贯穿游戏剧情的。

#### 4. 研究以下其中一个传统的艺术或设计风格的历史，并且写一篇简短的小论文以说明此风格是怎样帮助电子游戏来建立情感基调的：印象主义、构成主义、象征主义、流行艺术、装饰派艺术、新派艺术。请使用该风格下的著名画作或其他作品作为论据来支撑你的论点。
