# 2.1.2 以玩家为中心的方法

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：以玩家为中心、工艺、移情、娱乐职责、设计动机

## 原书内容整理

本书将要介绍一种称为“以玩家为中心的游戏设计”（player-centric game design）的方法。我们相信这一方法最有可能创作出令人喜爱的游戏，然后，这种喜爱将有助于它在商业上的成功。许多其他的因素也会影响一款游戏在商业上的成功：营销、配发和开发小组的经验。这些因素都超出了游戏设计者的控制，所以没有任何设计或开发的方法能够保证一定成功。然而，一款设计优良的游戏无疑要比设计差劲的游戏更有机会获得成功。“以玩家为中心的游戏设计”是一种设计哲学，在这一哲学指导下，设计者为自己想要创建的游戏设想一个玩家代表，设计者要因为这个玩家而接受两个关键的职责：

- 娱乐职责：一款游戏最主要的功能就是娱乐玩家，设计者的职责就是设计出这样的游戏。其他的动机都是次要的。

- 移情职责：为设计出娱乐玩家的游戏，设计者必须把自己想象成玩家，并且要创建出能迎合玩家娱乐愿望和喜好的游戏。“娱乐职责”在一些情况下可以进行调整，如游戏的意图是为了教育、研究、广告、政治或其他目的等。但是对于电子游戏来说，娱乐职责是最主要的。如果一个玩家将要在你的游戏上花费时间和金钱，你首先要关心的是要看到他能否自娱自乐。这就意味着提供给玩家娱乐是最主要的，而不是你要表达创造性的愿望。你必须为游戏进行有创造性的想象，但是如果这些想象有些方面和娱乐玩家不符，那么你应该对其修改或是消除。“移情职责”要求你把自己放到玩家代表的位置，并且想象一下你的游戏哪里好玩。你必须在心理上成为玩家并要站在他的角度考虑问题。对于你做出的每一个设计决定（可能是成于上方个），你都要问一下自己是否迎合玩家对交互式娱乐的愿望和喜好。注意我们强调的是代表性玩家。由你决定这个词的意思，但是这种假定的生物和实际购买游戏的消费者必须要有相似的观念。一个好的游戏设计师如果在正式设计之前不了解玩家，那么他们需要事先做好市场调查，以了解这部分玩家的偏好。以玩家为中心的游戏设计意味着要考虑玩家对游戏中的一切会做出怎样的反应：它的美感、它的用户界面、它的可玩性等。但是这些都只是表面性的。在更深的层面上，你必须理解玩家想从你所给出的完整体验中得到什么——即玩家玩游戏的根本目的是什么。要围绕着玩家来设计游戏，你就必须对以下问题有着清晰的答案：你的玩家到底是谁？他们的喜好是什么？他为什么要买你的游戏？对这些问题的回答也会受到你为游戏选取的游戏概念所影响。在第4章中将更为详细地介绍该方法。与玩家移情的过程可以把游戏从娱乐形式的表象中区分出来。在书籍、油画、音乐和电影的创作中，通常是从艺术效果上考虑的，而不用考虑它是否会被接受，如果因为销售上的考虑而对内容做出修改，则被认为是唯利是图。但是在电子游戏中——不管你是否认为它是艺术工作——你都必须考虑到玩家对游戏的感觉，因为玩家是带着思想和行动参与到游戏中的。我们认为，以玩家为中心的游戏设计会创作出更具娱乐性和受欢迎的游戏。然而，你必须避免两个常见误解。误解1：我就是我所设计游戏的典型玩家其实许多年来，设计者都是在为自己创建电子游戏。他们以为自己喜欢的，他们的客户也会喜欢。因为大部分设计者都是年轻的男性，他们就想当然地认为他们的客户基本上也是由年轻的男性组成的。在相当长的一段时间内，这种想法是正确的，但是现在它成了很危险的谬论。因为游戏市场的扩张已超出了传统的玩家群，你必须能够为其他各类玩家设计出游戏。在以玩家为中心的方法中，这意味着你要学会像你希望的玩家那样思考，而不管他们是谁：小女孩、老人、忙碌的母亲等。你不能假定玩家喜欢你所喜欢的。更恰当的是，你必须学会能为他们所喜爱的东西而设计。（可能会发现随着你的设计工作的不断深入，你会开始喜欢上一款游戏，而此前你认为自己是不会对它感兴趣的！）一些游戏开发者争辩说，他们不想为连自己都不喜欢玩的游戏而工作——因为如果这款游戏不能吸引他们，他们就不会对它有激情，也不会把设计工作做好。按照这种逻辑，那么小孩子们从来都不会有游戏可玩，因为小孩子们不能够为自己设计游戏。如果你坚持这种观点，那么你就不会对自己的游戏有激情，或者说不能把工作做好，这是以自我为中心的方式——和以玩家为中心的设计相反。我们更喜欢专业人士，而不是情绪型员工。专业人士会主动努力工作，并把工作做好而获得报酬，不会出于娱乐而选择设计自己喜欢的游戏。如果你是一个真正的专业人士，就能够为玩家而不是为自己创作出一款优秀的游戏。设计点拨：你不是自己游戏的玩家不要假定你是典型玩家的缩影。以玩家为中心的游戏设计要求你能想象出你的玩家是什么样子的，即使他们和你有很大的不同。误解2：玩家是我的对手因为街机（投币式）游戏曾经流行很长一段时间，所以街机游戏设计中的一些技术蔓延到了并不适合于它的其他类别中。街机游戏通过得到玩家更多的投币来赚钱。因此，它被设计得相当难玩，通常不会超过几分钟，继而使玩家输掉游戏。街机模型鼓舞着游戏设计者把她的玩家看成是对手。它暗示着设计者的工作是为玩家创造障碍，使玩家赢取游戏变得困难。对游戏设计来说这是一个影响深远的错误。它没有考虑到玩家的兴趣或是玩游戏的动机。它趋向于把“困难”等同于“有趣”，因此忽略了创造性游戏的潜力，在创造性游戏中根本就不存在有任何“困难”。如果你工作于多玩家竞争型游戏，就是玩家给予每个人挑战，你可能不会犯这样的错误。但是在设计单玩家游戏时这是一个很容易掉进去的陷阱，因为挑战的提出是取决于你的。不要忽视这样一个事实，你的设计目标是通过各种手段来娱乐玩家，而不是简单地阻碍玩家在游戏中的进展。设计者对于玩家的职责还包括同情，即不愿让游戏表现得过于任意妄为或反复无常。游戏中可以加入随机元素，让游戏变得更加困难和难以捉摸（就像随机抓到了一手烂牌）。这样做并无不可，只要让玩家相信他们下次手气会好一点就可以了。但如果让玩家一直这样输下去，而且没有任何规律可循，那这就不是好的设计，因为这种游戏缺少同情心。设计点拨：玩家不是你的对手不要把玩家想成是你的对手。游戏设计是为了娱乐玩家而不是和玩家对抗，娱乐玩家的方式有许多。
