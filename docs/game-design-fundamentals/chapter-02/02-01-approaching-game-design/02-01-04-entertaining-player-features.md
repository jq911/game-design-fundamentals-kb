# 2.1.4 娱乐玩家的游戏特点

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：以玩家为中心、工艺、移情、娱乐职责、设计动机

## 原书内容整理

当游戏开发是由一个特殊的动机来驱动时，常常结果是得到一个不合格的产品。好的设计者不会以牺牲其他特点为代价来寻求一个特点的最大化，而会整合游戏的所有特点以支持最高的目标：娱乐玩家。游戏特点包含以下儿点：

- 游戏必须要呈现出一个虚构的、连贯的体验，所以设计者必须有一个设想。

- 游戏必须要有好的销量，所以设计者要考虑玩家的喜好。

- 得到许可证的游戏必须为此付出代价，所以设计者必须要懂得许可证带来的好处，并要利用这些好处使游戏达到最大优势。

- 游戏必须要提供智力挑战和流畅的、无漏洞的体验，所以设计者必须要懂得技术。

- 游戏必须要能吸引人，所以设计者必须要考虑它的美学风格。以玩家为中心的游戏设计意味着对每一项元素、每一个特征的测试都要有标准可依。这一项有助于娱乐玩家吗？它能给予玩家娱乐了吗？如果答案是肯定的，就保留这些元素或特征。否则，你就应该考虑删除他们。并没有简单的公式来决定是否这样做，主要就是尽力而为。正像第1章我们曾经引用过的设计师BrianMoriarty的话一样，很多设计师“将毫无理由的特征堆砌起来，仅仅是为了炫耀它们”，这表明他们没有以玩家为中心进行游戏设计。有些时候包含一些没有直接娱乐效果的特征是有一定原因的：这些特征可能是游戏其他部分工作所必需的，或者由许可证的颁发者所要求的。但是你应该对它们抱着怀疑态度，并且努力降低它们对玩家的影响。
