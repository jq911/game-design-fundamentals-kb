# 2.1.3 影响游戏设计的其他动机

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：以玩家为中心、工艺、移情、娱乐职责、设计动机

## 原书内容整理

在商业游戏产业中，电子游戏通常是为娱乐而设计的，但即使是这样，依然有一些影响游戏设计的因素。在本节中，我们将对部分因素进行考查。当一家公司选择为特定的市场专门制作游戏，并为提高市场销售而在专门的设计中包含某些元素时，这种游戏就称为“市场驱动型”（market-driven）游戏。你可能会认为任何为销售而制作的游戏都是市场驱动型的。然而，经验表明，大多数市场驱动型游戏并不成功。你不能够通过简单地投入所有的可玩性的流行元素，制作出一款杰出的游戏。如果你这样做，那么就感觉不到它是一款特定的游戏了。最好的游戏是设计者想象力的表达，这样可以使它与众不同。与市场驱动相反的是“设计者驱动”（designer-driven）。在设计者驱动游戏中，设计者保留所有的创造性支配，并且无论在多么小的创造性决定中他都要扮演个人角色。通常这样做是因为他相信自己的创造能力优手其他任何人。这种方式忽视可玩性或其他人的集体智慧的好处，结果总是得到很拙劣的游戏。游戏《大刀》（Daikatana）就是一个常被弓引用的例子。许多发行商使用许可证代理开发游戏，许可证是一种特殊的知识产权，像书籍《指环王》，电影《虎胆龙威》，或运动商标“HNLHockey”。这能从中得到很大的利益。作为设计者，你将使用已存在的角色和世界进行创造性的工作，并且你将为那个世界的材料的规则做出贡献。设计被许可的游戏有一个缺点是，你没有完全按自己的想法来设计游戏的自由。许可证的所有者在游戏发行之前有批准你的游戏发行的权利，就像对他们不喜欢的事情要求你做出改变的权利一样。另外，还会有自满的风险。单单一个好的许可证对保证成功是不够的。设计出的游戏必须要像没有许可证时一样优秀。“技术驱动型”（technology-driven）的游戏是为了展示一种特殊的技术成就，通常是伴随着图形或硬件部件的。例如，除了取悦玩家之外，Crytek公司的游戏作品都在有意地展示自己强大的3D图像功能，并鼓励其他的开发者也采用这样的技术。当控制器制造商要发布新的平台时，总是会制作技术驱动型游戏来向人们展示新机型的特征。技术驱动型游戏的最大风险就是你要花很多时间关注于技术，而这些并不能肯定设计出来的游戏就真正好玩。因此单单靠一个许可证、一种新技术是无法保证游戏能取得成功的。“艺术驱动型”（art-driven）游戏相对较少。艺术驱动型游戏是为了展示某些人的艺术作品和审美情趣。尽管这种游戏是视觉上的创新，但是很少有非常优秀的，因为设计者在考虑呈现素材上要比考虑玩家对游戏体验上花费的时间多。一款游戏必须要有令人愉悦的可玩性，这和强烈的视觉效果一样重要。《神秘》就是这样一款游戏，它是带有很强可玩性的艺术驱动型游戏。
