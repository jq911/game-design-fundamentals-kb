# 2.5 游戏设计团队

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：首席设计师、机制设计师、关卡设计师、用户界面设计师、协作

## 原书内容整理

一个大型电子游戏通常是由一个团队设计的。在Hollywood 通常是行业协会和联盟定义工作任务，和 Hollywood 不同，游戏产业的工作头衔和责任在各个公司有不同的标准。公司会根据每个人的能力（更重要的是根据工程需要）来赋予他们的头衔和任务。然而，近年来，一些工作产生了变化，不管它们是哪个游戏或者工程的一部分，它们的职责都很相似。

- 首席设计师。这个人检查游戏的整体设计工作，并且她要保证游戏的完成和对一致性负责。她是最高级别以及最抽象级别的“远见保持者”。她经常在公司内外宣传游戏并作为项目的发言人进行发言。不是所有首席设计师的工作都是有创造性的。作为团队的领袖，她用创造性换来了权威，她的主要任务就是保证设计工作完成，其他的团队成员能正确地完成自己的任务。一个项目只有一个首席设计师。

- 游戏设计师。没有像下文中其他人一样负责专门的事情，但是几乎所有事情都和他有关，特别是定义游戏的玩法——玩家将面临的挑战以及为了克服这些挑战可以采取的行动。在设计过程中可能要思考和描述许多游戏元素：敌人、友好的非玩家角色、单位类型等。有时还会涉及游戏的大体关卡布局，以及规划玩家在游戏中的进展。小团队很少有专业的游戏设计师，每个人都是一个通才。

- 游戏机制设计师。游戏机制设计师定义和记录游戏如何作为一个系统实际工作：游戏的核心机制。它在游戏的心脏地带建立起了数学模型，从驾驶汽车到徒手战斗。游戏机制设计师还负责进行背景研究和组装游戏可能需要的数据，特别是游戏中基于真实世界的活动而产生的某种运动。

- 关卡设计师。关卡设计师获得游戏设计师提供的基本游戏组件（用户界面、核心机制和游戏可玩性），并使用这些组件设计和构建玩家将在游戏过程中通过的独立关卡。在大型游戏中，关卡设计师经常需要用脚本语言来构建3D 模型和程序。因此，关卡设计现在是一种专业技能或一组技能，被认为与游戏设计同样重要。一个项目通常包含儿个级别的设计师，并由设计部长或首席设计师领导。

- 用户界面设计师。如果一个项目把用户界面设计作为一个单独的任务，这个任务可能由一个或者多个人完成，他们负责在各种游戏可玩性模式中设计屏幕布局和定义输入设备的功能。对于大型复杂的游戏来说，这是一个全职工作。一个其他方面很成功的游戏可能会被一个糟糕的用户界面所毁掉，所以最好是使用一个专业人员。大的开发商越来越倾向于使用其他软件产业的专家来帮助他们测试和修改界面。

- 作家。作家负责创建游戏的说明性或者虚构的内容：介绍性材料、背景故事、对话、场景插叙等。一般情况下，作家不做技术上的写作，那些都由游戏设计者负责。很少有游戏需要全职作家，这些工作一般都承包给自由作家或者其他设计师来完成。其他4个职位在很大程度上影响游戏的创造性，虽然正常情况下他们不向首席设计师汇报工作。然而，游戏设计师总是希望能在项目过程中和他们进行频繁的互动和沟通。

- 艺术导演。也可以称为首席艺术师，管理游戏中所有可视资产的产品：模型、纹理、精灵、动画和用户界面元素等。艺术导演也在创建和加强游戏的视觉风格方面起着主要的作用。在团队的等级划分里，艺术导演通常和游戏首席设计师处于同一个级别，所以他们两个必须要具有良好的合作关系和相似的工程目标。

- 音频导演。和艺术导演相同，游戏的音频导演检查游戏中的所有音频资产产品：音乐、背景声音、音效和对话或者独白。典型地，这些材料没有艺术材料那么多，所以音频导演一次可以为几个项目工作。音频对创建游戏的气氛至关重要，首席设计师和音频导演一起来确定需要使用什么样的声音来达到希望的效果。设计点拨：不要以委员会的形式设计不要把设计工作当成是民主的过程，认为每一个人的选择都同等重要（即“以委员会的形式设计”）。一个人必须拥有做出最终决定的权威，而其他人必须服从这个人的权威。

- 首席程序员。首席程序员负责监督编程团队、游戏的技术设计以及软件的质量。如果你的设计文档中存在歧义或空白，并且你无法表述所有内容，那么首席程序员就会过来并要求你解释它们。处理硬件的技术限制也需要大量的沟通。程序员可能会发现你设计的东西太大或太复杂，无法实现，你需要与他们一起工作。除了小问题，你应该让首席程序员参与到编码人员的任何讨论中，因为你决定解决问题的方式可能会影响他们的日程安排或工作流程。

- 生产商或项目经理（或两者都有）。虽然游戏行业中的工作岗位并没有标准化，但游戏作为一种商业产品，它的总体责任还是由生产商来承担的。除了考虑未来发展，生产商还会与营销、公共关系和社区管理者（如果有的话）合作，在游戏发布之前进行造势。生产商通常期望在设计中有大量的创造性投入，他们期望对昂贵或不可行的建议有否决权。生产商还可以跟踪游戏开发过程的日常进展，确保任务完成，因为没有人会愿意一动不动地坐等事情发生。在一个足够大的团队中，可以将这个工作委派给一个项目经理。其他领导也会与项目经理合作来完成这项任务。游戏理念与设计决策这是一个游戏想法：“龙应该保护它们的蛋。”这是一个设计决定：“无论何时，只要龙的巢中有蛋，那么母龙就都不会让她的巢穴离开视线范围。如果敌人闯入了距离巢穴50米之内的地方，龙就会停止任何其他活动并返回巢穴中来保护自己的蛋。它们会一直守护着龙穴，直到敌人离开方圆50米的范围至少30秒以上。龙会尽最大努力来保护自己的蛋。明白其中的不同之处了吗？这就是创建设计文档时所关心的问题。
