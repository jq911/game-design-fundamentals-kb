# 2.1 走近游戏设计

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：以玩家为中心、工艺、移情、娱乐职责、设计动机

## 原书内容整理

在讨论游戏设计过程之前，我们必须先讨论如何处理游戏设计——这就是实际上你要完成什么以及你如何来思考它。近年来，人们尝试了很多方法来进行游戏设计，有些方法29要好一点，而有些方法却走向了灾难性的失败。因此本书将教会你游戏设计的工作要完成什么和如何来思考它，从而让设计者工作更趋近于成功，而不是失败。
