# 2.7.5 美学能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

虽然你不必是一个艺术家，但是应该具备一般的美学能力和某种时尚感。现在太多的游戏都是彼此之间视觉上的克隆，都依靠老套和陈腐的东西，而不是真正的想象力。你（和你的首席艺术师）来设置游戏的视觉色调以及创造一个一致和谐的外表。尽可能拓展你的审美宽度。学习一点有关艺术的基础知识：创作原理以及什么颜色相称，什么颜色冲突。找出著名的艺术流派——新艺术主义、超现实主义、印象流派——观察东西的方式。观赏一些因视觉风格著名的电影，例如《大都会》。然后，转移到更加实际的艺术：建筑学、内部装潢、工业设计。你拥有越多的艺术经验，就越有可能生产出艺术创新的产品。
