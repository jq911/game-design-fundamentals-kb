# 2.7.2 技术知识

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

技术知识是关于计算机程序的，特别是游戏的工作原理的一般理解。你不必是一个软件工程师，但如果具备一定的编程经验会非常有利。特别是关卡设计师，通常需要能使用简单的脚本语言进行编程，他要知道目标平台的技术性能。你也必须知道不能做的事情，这样你就不会做出不可行的设计，例如许多低端的手机不能对3D图形有足够强的处理能力。
