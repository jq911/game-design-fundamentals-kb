# 2.7.4 数学能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

设计师必须具备基本的数学技能，包括三角学和概率论的一般原理。要平衡复杂的内部经济发挥着很大作用的游戏，比如商业模拟或者实时策略游戏，可能会让你花费大量的时间观察各种数据。你不需要拥有数学博士学位，但应该有足够的数学知识。
