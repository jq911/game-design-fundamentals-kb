# 2.7.3 分析能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

分析能力是学习和研究某些东西的能力：想法、问题或者整个游戏设计。没有一个设计一开始就是完美的，游戏设计是一个反复修改的过程。因此，你必须能够认识到一个设计的优点和缺点在哪里。分析任务的一个例子就是在设计阶段检测无敌（或几乎不可战胜）的策略，并在转变为代码之前把它们去除掉，就像声名狼籍的《红色警戒》“坦克流”。在《命令与征服：红色警戒》中，苏维埃一方的坦克比其他任何单位都有效得多，因此有经验的玩家就会把资源都用来制造坦克，然后迅速地在敌人还没有机会建立起生产线的时候横扫对方的基地。
