# 2.7.8 绘画能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

某些基本的绘画和素描技能也是非常有用的，如果你和概念艺术师一起工作，这不是对一个设计师的绝对要求。大量主流的计算机游戏在很大程度上都依靠视觉内容，当把游戏介绍给第三个团体的时候，绘画是基本的要求。游戏发行执行人将会对热点概念、热点市场或者热点许可证感兴趣，但是只有图片可以真正打动他们。在他们忘记细节很长时间之后，图片也会停留在记忆中。
