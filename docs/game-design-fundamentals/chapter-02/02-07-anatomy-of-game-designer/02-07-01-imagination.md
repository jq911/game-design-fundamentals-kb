# 2.7.1 想象力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

游戏存在于一个人工世界中，一个由假想的规则统治的假想的地方。想象力是创建这种地方最基本的要求。它有以下几种形式：

- 视觉和听觉想象力可以让你思考新的建筑、树木、动物、生物、衣着和人类——他们的外表和声音。

- 戏剧性的想象力可以用来开发好的角色、情节、场景、动机、情绪、高潮和结局。概念想象力是关于想法、相互作用和独立性之间的关系。横向思考是寻找可替换答案的过程，采取意想不到的方法解决问题。

- 演绎是从你做出的创造性决定到它可能产生的结果的推理过程。一般不认为演绎是想象力的一部分，但是你得到的结论会为游戏产生新的素材。

#### 设计点拨

想象力不仅仅由发明新事物的能力组成。能够研究一个旧的想法，通过一种新的方法使它获得新生也是很有价值的。J.K.Rowling就在她的《哈利·波特》小说中辉煌地做到了这一点。她仍然有坐着扫帚飞行的女巫，但是她发明了Quidditch这种运动，可以在飞行的时候进行这种运动。
