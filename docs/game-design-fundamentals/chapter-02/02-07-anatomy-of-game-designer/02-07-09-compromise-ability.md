# 2.7.9 妥协能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

要协意味着把不同的想法整合到一起，并从中创建出一些新的东西，开发团队和发行公司中不同的人会关心自己擅长领域内的东西（编程、艺术、音乐等），他们的意见会影响游戏的发展方向。作为设计师，你也可能想寻找游戏蓝本的单独所有权，并且坚持所有东西都要跟你想象中的一样。你一定要抵制这种诱惑，原因有两个：

- 第一，你也必须允许你的团队具有游戏蓝本的某些自主权，否则团队的成员对这项工作就没有任何动力或者激情了。没有人只是为了钱去开发一款游戏，我们在这里因为我们可以贡献创造性。

- 第二，一个不能在团队环境中发言的设计师，不管她多有远见，也不会被雇用很长时间。你必须可以成功地跟其他人一起工作。游戏设计总是需要与团队成员和环境妥协。在一个大公司里，你可能会被指派一项限制你在一种类别克隆或者在一个许可证产权下的任务。除非你是一名独立的游戏设计师，否则几乎必然会受到限制，而不是选择游戏将要运行的目标硬件。你的项目通常都会有一个急切需要满足的预算和时间表。一个专业的设计师一定要能在这些限制下工作，并且做出必要的要协来完成这些任务。
