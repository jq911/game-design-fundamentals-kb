# 2.7.7 写作能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

专业的游戏设计师实际要花费大量的时间写东西，所以一个设计师必须具备优秀的写作技能。也就是说要清晰、简明、准确和明了。除了要为每个设计写一份详细的文档外，你可能还要写出敌事叙述材料或者对话——特别是当预算不允许再请一个编剧的时候。设计写作通常有以下几种形式：

- 技术写作是为开发做准备的设计过程的记录。游戏的基本机制都必须在这里精确明了地回答。

- 小说写作（记叙）作为一个整体创作游戏故事——如果游戏有很强的故事情节，这将是设计过程很关键的一部分。某些材料可能会以文本或者语言叙事的形式出现在最终完成的产品中。游戏手册（如果有的话）也经常包含小说材料。

- 对话写作（戏剧）被用于画外音和影片材料。对话表达了角色的性格，它也可能形成情节的一部分。剧本创作或者电影创作的课程可以帮助你学会对话写作的很多东西。一个设计师必须可以向团队的其他成员传达设计的细节，创建出将出现在文本和口头上的材料，并且帮助把想法出售给发行商。优秀的写作技能是完成这些东西的基本要求。
