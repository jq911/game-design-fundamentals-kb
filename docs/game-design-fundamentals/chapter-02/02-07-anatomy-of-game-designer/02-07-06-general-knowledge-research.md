# 2.7.6 常识和调查能力

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

最有想象力的游戏设计师都是受过很多教育且兴趣爱好广泛的人。精通历史、文学、艺术、科学和政治事件这样的主题会很有帮助。更重要的是，你必须知道如何研究游戏中的主题。使用互联网上的搜索引擎也是很诱惑人的，但是那不是很有效，因为它表现出的信息都是随机的，而且组织比较混乱，还有可能不太可靠。百科全书是开始学习某个主题不错的地方。在那里，你可以通过查阅更加专业的书籍或者电视文档来增加某个专门领域的知识。
