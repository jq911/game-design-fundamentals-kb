# 2.6 游戏设计文档

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：设计文档、高级概念、游戏处理文档、流程板、游戏脚本

## 原书内容整理

作为游戏设计者工作的一部分，他们必须创建一系列文档来告诉其他人有关游戏设计的信息。他们创建的文档的内容以及作用因设计者和工程的不同而不同，但是他们通常遵循相同的思路。
