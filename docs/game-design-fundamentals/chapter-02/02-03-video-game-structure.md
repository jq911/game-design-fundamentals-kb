# 2.3 电子游戏的结构

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：游戏可玩性模式、shell 菜单、shell 屏幕、结构转换

## 原书内容整理

现在你已经知道游戏的核心机制是如何与用户界面一起来为玩家创建游戏可玩性的。然而，一个游戏不会一次呈现出它所有的挑战，它也不允许玩家在所有的时间里都使用所有的动作。相反，大部分电子游戏呈现出的都是它们全部游戏可玩性的一个子集，通常使用一个特殊的用户界面来支持这个子集。当玩家被要求迎接一个新的挑战或者从另一个视角观察游戏世界时，可用的游戏可玩性和用户界面就会改变。有时为了回应玩家做出的某些动作也会发生这些改变，其他时间在核心机制确定这些改变应该发生的时候它们会自动发生。这些改变如何发生以及为什么发生是由游戏的结构确定的。结构由游戏可玩性模式和shell菜单组成，其中游戏可玩性模式是游戏设计方法中一个至关重要的概念。在这一部分，我们将定义什么是游戏可玩性模式及shell菜单，还将讨论它们是如何交互来形成结构的。
