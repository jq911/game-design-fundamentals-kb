# 2.7 剖析游戏设计者

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 2 章。  
> 关键词：想象力、技术知识、分析能力、数学、美学、写作、妥协

## 原书内容整理

和所有的工艺一样，游戏设计既要求天赋，也要求技能。天赋是天生的，但是技能是可以学到的。高效的游戏设计师要求具有广泛的基本技能。下面将讨论对专业游戏设计师最有用的几种技能。如果你没有拥有全部这些技能，不要气铵。这只是一个理想的列表——我们希望一个假想的理想设计师所拥有的特质。
