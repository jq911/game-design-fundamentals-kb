# 5.3.1 典型用法

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：便携设备、移动电话、手持设备、触摸屏、电池、应用商店

## 原书内容整理

便携式设备被设计成可以由一个人携带和使用。这种设备的尺寸范围从相当小的移动电话到平板计算机，其大小几乎是膝上型笔记本的尺寸。使用情况的区别关键在于设备是否适合放于口袋中。如果是，它几乎可以去任何地方；如果不是，用户必须有一个钱包、公文包或背包将其放入。一些只适合大口袋的中型设备现在也有。因为用户会用手握持便携式设备，所以用户的眼睛比任何其他设备都离屏幕更近。屏幕尺寸是一个关键的限制，不幸的是，几乎每个设备的制造和型号都是不同的，屏幕分辨率也有很大的不同。这意味着用户界面必须非常简单和清晰，甚至应比在大电视屏幕上显示的控制台游戏更简单。由于便携式设备经常在公共场合使用，每个游戏必须包括一种关闭声音的方式，即使设备本身也有主音量控制。玩家有时想要为他们的设备关闭主音量，以便可以听到传入的短信或电话通知，但是关闭游戏声音，可以防止它们影响周围的人。电池寿命也会影响便携式设备的使用。游戏往往是CPU和图形密集型应用程序，你不能指望玩家长时间玩游戏，而无法在其他机器上保存游戏。因为在任何时候，他都有可能需要接听电话或关闭设备来省电。
