# 5.3.3 专用游戏手持设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：便携设备、移动电话、手持设备、触摸屏、电池、应用商店

## 原书内容整理

最便宜的手持机提供一组固定的内置游戏，但是更通用的手持机则接受存储在盒式磁带上的游戏，并且PSP支持小光盘。盒式磁带存储的数据比家用控制台和计算机使用的CD-ROM或DVD光盘少得多。盒式磁带的设计会严重限制玩家在游戏中体验的元素，包含视频、音频、图形和动画的数量。因为它们是固态电子，所以盒式磁带上的数据立即可用，加载数据没有延迟。因为光学介质设备的存在，所以没有磁带损坏的危险。手持游戏市场有着不错的潜在利润，但能否创造出一个盈利的游戏是考验你作为一个设计师的技能。随着存储空间的减少，你必须依靠游戏玩法，而不是内容来提供娱乐。人们玩这些游戏的正常方式是一次只有几分钟，而不是一个小时，它们可能在任何时间被中断，你的游戏设计必须满足这些期望。与家用控制台机器一样，要开发专用手持游戏机，你必须拥有制造商的许可证。虽然有越来越多的数字发行的选择，专用游戏手持设备的游戏仍然倾向于在零售销售。
