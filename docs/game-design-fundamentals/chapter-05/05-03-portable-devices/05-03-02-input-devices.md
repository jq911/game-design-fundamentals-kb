# 5.3.2 输入设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：便携设备、移动电话、手持设备、触摸屏、电池、应用商店

## 原书内容整理

便携式设备的一个特点是用户在使用设备时必须支持设备的重量。举着它有时会影响到它的可用性。使用控制台控制器的玩家也必须举起它们，但是因为大多数控制台控制器没有屏幕（Wii U的GamePad是个例外），控制器可以更好地设计以适合双手来使用。此外，放弃普通控制器的后果比较可怕，便携式设备往往是非常脆弱的。手持机几乎不支持附加功能，输入和输出设备通常是固定的。这些机器比控制台控制器具有更少的按钮（相对于智能手机而言）。然而，与控制台或个人计算机不同，便携式设备通常包括全球定位系统，使玩家能够通过移动在现实世界中创建AR（增强现实）类游戏。任天堂的DS和3DS系列在专用游戏手持设备中是独一无二的，因为它们有两个屏幕，其中一个是触摸敏感的并且可以与触笔一起使用。
