# 5.3.4 手机和无线设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：便携设备、移动电话、手持设备、触摸屏、电池、应用商店

## 原书内容整理

移动电话现在有足够的计算能力来玩画面优质的游戏。研发了很多的手机带来的最糟糕的事情便是缺乏统一的标准。不同品牌的手机屏幕都有不同的尺寸和颜色深度，处理器和操作系统也不同，甚至按钮的布局也是非标准的，在一系列手机中根据用户界面确定何种操作是非常困难的。如果你为手机开发游戏，预计在不同的硬件上需要做很多兼容性测试。与专用游戏手持设备不同，手机和平板电脑以多种不同的方式销售游戏。有些是简单地以固定费用的形式出售——通常远远少于控制台游戏的成本。有些是基于时间的订阅被出售的，还有许多是免费的，然后通过所谓的应用内购买（IAP）——允许玩家支付少量费用来购买物品，或玩过某一节点，或更频繁地玩游戏（这通常被称为免费模式，在第6章中将更详细地讨论）。如前所述，家用游戏机是封闭系统，为它们进行开发通常需要制造商的许可证，PC有一个任何人都可以开发的开放系统。在这个问题上手机被分开了。苹果为他们的设备开发游戏（或任何其他应用程序）不需要许可证，但他们坚持认为游戏只能通过他们的App Store分发。他们还对游戏中允许的内容以及通过iTunes销售的书籍、音乐和其他内容进行编辑控制（有时甚至是反复无常）。然而，这种控制不采取先前约束的形式，因为它有时在控制台上。开发人员偶尔会在App Store上出售一个产品，但后来发现它已被删除。Google Play商店（适用于Android设备）也对其允许的内容进行编辑控制。但是，没有必要通过Play商店分发你的游戏。如果想避免遵守Google的政策，你的Android手机玩家可以直接从网站下载安装文件，或将其作为电子邮件的附件接收。从营销的角度来看，这是不理想的，因为大多数临时用户都会在Play商店和其他地方寻找游戏，他们必须让手机允许安装未知来源的应用程序。针对手机进行游戏开发已经变得如此容易，以至于市场上有巨大的过剩，许多开发商从未盈利。另一方面，那些有幸能够获得成功的人可以获得惊人的利润。《愤怒的小鸟》便是这样一款游戏，但它确实也实至名归，作者Rovio在《愤怒的小鸟》之前已经设计了51款不那么成功的游戏。
