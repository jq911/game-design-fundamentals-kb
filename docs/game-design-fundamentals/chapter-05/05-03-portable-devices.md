# 5.3 便携设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：便携设备、移动电话、手持设备、触摸屏、电池、应用商店

## 原书内容整理

便携式设备是一种非常流行和便宜的娱乐设备。早期的便携设备是为专用手持设备设计的，只能玩几个内置的游戏（有时只有一个），主要被用作儿童玩具。从那时起，它们已经有越来越多的分支，玩家范围从小孩扩大到了成年人，成为了中等强度和灵活的计算设备。它们的CPU比计算机的CPU运行速度慢，但仍然有足够的能力运行复杂的游戏。索尼PSP代表了专用手持游戏机在功率和画面质量上的巨大飞跃。移动电话和其他联网设备（如Nintendo DS）相对于传统的游戏手持设备具有明显的优势：它们允许便携式网络游戏。玩家可以在乘坐火车或等待约会时与他人联网游戏。在移动电话上设置网络游戏通常需要与手机服务提供商进行数据传输服务。此外，与专用的游戏机不同，大多数手机不需要硬件制造商的许可证。任何人都可以为手机编写程序。
