# 5.4 其他设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：航空座椅游戏、视频赌博机、街机、位置娱乐系统、小众设备

## 原书内容整理

现在游戏可以显示在各种各样的其他设备上。设备越专业化，就越能清楚地了解其技术限制和玩家的重要性。航空公司开始在他们的座位上安装电子游戏，这些游戏往往针对儿童或休闲市场。视频赌博机也越来越受欢迎，因为它们受到严格监管，所以不会单独卖给消费者，它们自身真正构成一个行业，但视频赌博游戏需要程序员和艺术家，就像任何其他计算机游戏一样。当然，街机虽然不像以前那么流行，但仍然为游戏开发商提供就业机会。最后，还有大型的基于位置的娱乐系统，如主题公园的驾驶模拟器。这些装置不是提供实际的惊险骑乘，而是使用由活塞移动平台上的座椅，结合大屏幕显示器，以产生运动的错觉。玩家可以使用与其座位相连的输入设备进行体验。因为这些设备占据了小众市场并且通常具有特殊的设计限制，因此本书不会详细讨论它们。
