# 5.5 本章总结

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：总结、设备类型、优势弱点、场景、复杂性

## 原书内容整理

在本章中，我们分析了三大类游戏设备：家用游戏机、个人计算机和便携式设备。每种设备都有自己的优势和弱点，它们之间永远不会完全融合。控制台最好用在客厅，那里有一些受控的空间可以操作；计算机最好由玩家在办公桌上使用：便携式设备为了方便和易于开发而折中了游戏的复杂性。因此当你在设计游戏时要考虑运行游戏的设备，也要将它们的特点考虑进去。
