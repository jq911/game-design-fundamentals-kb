# 5.6 设计练习——训练

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：训练题、设备类别、游戏类型、零售商店、应用商城

## 原书内容整理

#### 1. 同一类机器上通常会出现同一种特定类别的游戏。写一篇文章阐述每个类别的游戏在哪

种类型上的机器上运行得最好，并说明原因。试分析家用设备和掌上设备的特性和用途，以及影响各流派类别运行的特性。

#### 2. 参观一家零售商店并观察该店的商品架，然后再去网上应用商城。记录下你在每个地方

所观察到的游戏类别，并数出属于该类别中的游戏数目。请思考不同机器上运行的游戏或类别之间的差异。
