# 5.2 个人计算机

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：个人计算机、键盘鼠标、独立游戏、网页游戏、开放平台

## 原书内容整理

个人计算机在市场上出现的时间略晚于家用游戏机，虽然现在是一款通用的计算设备，但早期的计算机大多能力有限，不足以满足家庭办公或商业用途的需要。然而，它们作为游戏平台却十分迅速地取得了成功，Commodore64、Atari ST、Amiga和其他个人计算机在游戏玩家和早期的计算机爱好者中广受欢迎，最特别是因为其所有者可以开发属于他们自己的游戏。一些杂志会刊登游戏的源代码，让发烧玩家用于使用和修改。但他们始终没能超越业余爱好者这个范畴，直到1981年，IBM推出了IBM PC。在这本书中你会看到许多对个人计算机的引用。IBM PC和其衍生机（运行Windows的操作系统）是到目前为止用于游戏的最受欢迎的个人计算机。但是，当你看到PC一词，你不应该假定它只是运行Windows的IBM PC，不包括其他的桌面机，因为PC可以是笔记本电脑或平板设备。开发人员也为麦金托什机设计游戏，机器运行Linux操作系统，这些也有资格作为PC。就我们的目的而言，真正的PC就是键盘和鼠标的代表。
