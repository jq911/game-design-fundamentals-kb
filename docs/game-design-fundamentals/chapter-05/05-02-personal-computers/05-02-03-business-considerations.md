# 5.2.3 业务考虑

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：个人计算机、键盘鼠标、独立游戏、网页游戏、开放平台

## 原书内容整理

PC端游戏开发的巨大优势是任何人都可以进行编程，你不必得到制造商的许可或购买昂贵的开发站。因此，个人计算机处于计算机游戏创新的前沿。它们是交互式艺术和其他实验形式的娱乐互动的首选平台。移动设备也能进行类似简单且廉价的开发，但是它们还没有达到与PC端具有相同表达能力的水平。但是，这一现象可能很快就会被改变。PC端开发遇到的巨大瓶颈是没有两台计算机是完全一样的。因为个人计算机的配置是因用户个人而异的，因此可能有数百万种配置。这在早期的游戏行业中，对于游戏程序员来说是一个真正的梦。但幸运的是，Windows和Macintosh操作系统以及像Unity这样的中间件解决方案通过将程序与硬件隔离解决了许多类似问题。与其他应用程序相比，游戏往往需要更多的机器，并且仍然会发生配置冲突。PC游戏可以分为两种常见的但却完全不同的类型：玩家像其他程序一样安装在自己计算机上的独立游戏，以及在网络浏览器内运行的、基于浏览器的网页游戏。

#### 1. 独立游戏

独立的PC游戏可以使用PC的全部功能，如果玩家在同一时间没有运行其他应用程序的话。在消费设备上玩的所有游戏中，独立的PC游戏可以说是视觉上最为壮观的。而家用游戏机会将不同的硬件以“第X代”的形式出售，给定的制造商的控制台直到下一代产品出现前将不会改变。相比之下，由于个人计算机不断发展，因此游戏开发者可以利用最新的硬件进行创新。Crytek的《孤岛危机》是一个很好的例子，它需要非常强大的计算机配置，才能让玩家充分享受到它的娱乐性。这并不意味着独立的PC游戏总是需要高端设备的，或者它们应该就这样，它只意味着如果你想开发最高档的装备，应该建立独立的PC游戏。这种选择通常限制了你的市场规模，真正专业的游戏爱好者将会购买最新的PC技术。另一方面，许多独立游戏瞄准范围的中间地带，并且做得很好。

#### 2. 网页游戏

基于浏览器的网页游戏是游戏市场中增长较快的部分。相比独立游戏，网页游戏有一个巨大的优势：它们在网络浏览器中运行，与机器的硬件有些隔离。基于浏览器的游戏可以在Windows PC、Macintosh或Linux计算机上运行，无需修改。然而，这个优势是有代价的，基于浏览器的游戏不能充分利用机器的能力。大多数网页游戏中有成千上万的游戏是针对休闲玩家的2D游戏。它们通常使用Java或Adobe的ActionScript语言编写，可与Flash Player一起使用。开始使用基于浏览器的游戏是开始构建小游戏的绝佳方式，因为用户不必了解机器的硬件，在不同平台之间游戏将更容易移植。
