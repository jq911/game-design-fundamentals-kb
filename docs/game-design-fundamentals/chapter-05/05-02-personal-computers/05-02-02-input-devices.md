# 5.2.2 输入设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：个人计算机、键盘鼠标、独立游戏、网页游戏、开放平台

## 原书内容整理

键盘和鼠标是PC和笔记本计算机独有的设备。使用含有101个键位的键盘，可以让游戏采用更复杂的用户界面，从而制作出更复杂的计算机角色扮演游戏（RPG），如《指环王》在线网游。键盘使玩家可以方便地输入文本，并通过网络向其他玩家发送聊天消息，这对于控制台机器来说是不太方便的。
