# 5.2.1 典型用法

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：个人计算机、键盘鼠标、独立游戏、网页游戏、开放平台

## 原书内容整理

一台个人计算机有可能远离公共生活空间，放在桌子上设置。它的设计可以由一个坐在它面前的人管理。在这种情况下，玩家有键盘、鼠标，可能还有操纵杆和（很少）那些为控制台机器专用的游戏控制器。玩家坐在距离高分辨率显示器12至18英寸远的地方（1英寸=0.0254米）。此高分辨率意味着游戏可以有微小、详细的图形。鼠标允许精确指向和更复杂的用户界面。键盘使玩家能够方便地输入文本。玩家接近屏幕可以创造身临其境的体验。一些玩家甚至添加额外的左右屏幕来显示一部分游戏世界，以及其周边的视角。这可以帮助他们更好地看到赛车游戏和在线多人游戏中战斗的对手，它还有助于他们沉浸在游戏世界。个人计算机是相当尴尬的，因为每次不止一个人使用。PC控件都是为个体设计的，或放在家具设计（一张桌子）用于孤立。笔记本计算机虽然很便携，但还不是很方便，除非在桌上。这就是为什么它们都包含在这里而不是在后面章节的原因。
