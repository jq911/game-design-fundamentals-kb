# 5.1.3 业务考虑

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：家用游戏机、控制器、客厅、许可、开发工具包

## 原书内容整理

家用游戏机的图形显示硬件和个人计算机的图形硬件一样强大，但是它的中央处理单元运行得比较慢，而且RAM比较小。因为一般发行一年左右的家庭游戏机的售价通常为200～400美元，所以制造商不得不削减硬件设计来降低成本。也就是说，作为计算设备，家庭游戏机没有个人计算机强大，而且使用家庭游戏机进行游戏编程更困难。另一方面，低廉的价格和易于维护的性能使它们更加普及，这就为这种游戏创造了更大的市场。家用游戏机和个人计算机还有一个非常大的不同。那就是家用游戏机的制造商不会随随便便就让其他人基于自己的产品来设计游戏，你必须从制造商手中拿到设计许可证，并让他们认同你对这款游戏的设计想法——然而他们更倾向于批准那些不会引发争议的游戏（尽管20年前的争议话题在现在看来已经变得无关紧要了，这得益于大众品味的变迁）。一旦游戏设计好，你还要在游戏发布之前将其提交给游戏机的制造商进行大量的测试。制造商通常会感到十分不耐烦，因为放在他们游戏机上的所有游戏都必须无故障和易于使用，多出来的测试无疑会增加大量的工作。制造商们非常重视对于自身品牌声誉的维护，而在开发个人计算机端的游戏时，不会出现这样多的顾虑。你可以创建你想设计的任何游戏，不需要获得其他人的许可。显然一些出版商（或分销渠道像App Store）不会公布他们觉得可能会是令人反感或非法的和许多国家已有法律禁止的某些内容的游戏。但PC是一个开放的平台，你可以构建个人计算机游戏不受任何合同的限制。相关的复杂性与PC不同，控制台机器的内部工作是一个商业机密。若要获取一个开发许可证，你必须与制造商签署一份保密协议，承诺不会向其他人透露任何细节，这一因素也使得控制台游戏更难获得帮助。为了构建控制台机器的游戏，你还必须有一个名为开发工具包或工具包的硬件设备。你必须从控制台的制造商处购买此设备，并且可能极其昂贵。相比之下，拥有PC的任何人都可以编程PC，它不需要任何特殊的硬件就可以获得一个程序。家用游戏机还会带来一个比较复杂的问题，就是它不像PC，家用游戏机的内部工作机制是一项商业秘密。因此要开发家用游戏机上的游戏，需要先获得一个开发许可证，而这么做的话你就必须与制造商签署一个保密协议，其中会要求你承诺不对任何人透露任何细节，这一要求会使游戏在开发过程中难以获得帮助。为了构建家用游戏机上的游戏，你还必须有一个名为开发工具包或工具包的硬件设备。你必须从家用游戏机的制造商处购买该设备，它可能非常昂贵。相比之下，拥有个人计算机的任何人都可以进行编程，个人计算机不需要任何特殊的硬件来开发一个程序。过去几年中，家庭游戏机和PC之间产生了部分重叠。家用游戏机现在通常都会带有磁盘驱动器，从而可以让玩家存储比以前更多的数据，而且现在的家用游戏机都具备了联网功能，联网进行游戏现在在家用游戏机上是很常见的。并且诸如Xbox LIVE之类的服务所提供的可下载游戏已经对传统零售商业模式造成了相当大的压力。
