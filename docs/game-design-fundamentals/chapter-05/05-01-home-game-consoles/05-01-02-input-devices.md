# 5.1.2 输入设备

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：家用游戏机、控制器、客厅、许可、开发工具包

## 原书内容整理

在控制台游戏中，控制器提供的控制方法和用户界面必须易于管理，例如鼠标应比控制台的控制器使用更方便。尽管如此，你必须保证每台机器都附带了一些标准化的控制器，这意味着你不需要做PC游戏有时需要的配置测试。一般来说，硬件开发人员为控制台机器创建品种非常多的输入设备——转向车轮、吉他、康加鼓、钓鱼竿、平衡板，等等——比他们为PC所做的设计要多。因为控制台厂家严格测试带有他们标志的任何设备，你可以确信这些设备必须与他们的机器相匹配。2006年任天堂通过引入带有革命性的动作感应控制器Wii来挑战现有的惯性。很多休闲玩家觉得传统游戏控制器上大量的按钮和操纵杆令人生畏。Wii让电子游戏变得更直观和容易上手，因此带有Wii的游戏设备在一些非常规的领域使用很广——如伤患、残疾、老年人等玩家群体。微软Xbox的Kinect运动捕捉设备是另一个重大突破，虽然到目前为止它相较于Wii 的影响还比较小。Kinect运动捕捉设备同样被设计为用在开放空间里玩耍的游戏中。对于任何需要大量体力活动的游戏来说Kinect无疑是另一个上好选择。
