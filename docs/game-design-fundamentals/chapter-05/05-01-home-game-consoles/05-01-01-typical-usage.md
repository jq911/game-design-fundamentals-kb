# 5.1.1 典型用法

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：家用游戏机、控制器、客厅、许可、开发工具包

## 原书内容整理

家用游戏机通常是在客厅或卧室中设置的。玩家坐或站立着持有一个作为显示的3至10英尺（1英尺=0.3048米）的专用的控制器而远离目前仍在使用的电视机。虽然如今的高清晰数字电视已经有了很大的进步，但在模拟端仍使用早期的控制台，玩家仍然需要从屏幕很远的地方观察细节或阅读小字。这意味着为家用游戏机设计的游戏不能与为个人计算机游戏设计的一样复杂，图形必须是更简单、更大胆。因为几个玩家看到的都是同一个屏幕，而且所有控制台至少会允许有两个控制器，控制台机器非常适合玩多玩家的本地游戏，所有的玩家都在看同一个屏幕上。它们非常适合聚会游戏、跳舞游戏、体育游戏和任何形式的轮流玩耍其他人旁观的游戏，比如《Wii运动：保龄球》。另一方面，控制台游戏不太适合需要个别玩家拥有秘密知识的游戏，因为每个玩家可以看到其他玩家在屏幕上的游戏。此外，因为他们在私人住宅内进行，玩家可以身处其中只会受到少量的干扰，所以游戏在设计和确定步调时可以参考这一点。而手机游戏只需要玩家花费数分钟，不是几个小时。家用机是专用的游戏机。它们不像计算机那样有许多其他功能，虽然只需一会儿功夫就可以为它们添加键盘——但这些从未真正流行起来。虽然使用这种家用机有可能连接上网络，但键盘和点击设备的缺乏会限制这种体验。控制台机器旨在针对专用的爱好者和儿童（或是给他们买的父母，）——都是些准备花大量时间玩游戏的人。
