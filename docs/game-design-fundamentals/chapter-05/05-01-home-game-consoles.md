# 5.1 家用游戏机

> 来源：私人资料库 OCR 整理，摘自《游戏设计基础（原书第 3 版）》第 5 章。PDF 为扫描版，文字已做轻度校正，仍建议以后逐段人工复核。  
> 关键词：家用游戏机、控制器、客厅、许可、开发工具包

## 原书内容整理

一说到“电子游戏”这个词，大多数人都会想到家用游戏机，即使在用手机玩游戏已经大行其道的今天，家用游戏机作为老旧的控制台机器仍能使用。在本节中，我们会看看人们如何使用控制台以及它如何影响我们为此设计的游戏。
